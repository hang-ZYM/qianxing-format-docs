## 一、组件系统定律 [A]

```
组件   = { f1: 组件ID, f(组件ID+10): 配置载荷 }        ← 定律：配置字段号 = 组件ID + 10
实体四槽: f5 行为 | f6 编辑器 | f7 资源 | f8 表现/引用(带 f2=1 标志)
```

- **f7 = 资源槽**（挂点/受击特效/实体变量等）。原 11/12 卷通篇标"AI 属性"系语义错标，勘误 2026-10-04。
- **实测映射链** [A]：组件 1→f11、2→f12、7→f17、11→f21、13→f23、22→f32，全部吻合 ID+10。
- **违律记录**：原卷记 comp26→f37、comp42→f53（违反 ID+10，按定律应 f36/f52）——本册按定律写 f36/f52，原卷两处记录待对字节复核。
- 官方 prefab 出厂自带一套"底盘组件"，实体差异来自选择性组件与配置值——合成/克隆保留底盘、只改配置（02 册：字节级复现官方实体的原理）。**f22 属性注册表 ↔ 组件实例**：f22 注册表（docs/10）= 模型声明层（本图启用的属性模型类名 + 启用位图）；实体组件 = 值实例层，改属性值改组件载荷、不动 f22。

## 三、使用配方

### 1. 变换（f6 槽组件 1 → f11，基准 schema）

```
f11 = { f1: {f1: x, f2: y, f3: z},     ← 位置，单位米；y 整体省略 = 贴地
        f2: {f2: yaw},                 ← 旋转，单位【度】！写 90.0 而非 1.5708
        f3: {f1: sx, f2: sy, f3: sz},  ← 缩放，默认 1/1/1
        f501: -1 }                     ← 模板默认标记，保留
```

- **悬空 = 补 `f11.f1.f2`（y 坐标）**——不是补 f11.f2（那是旋转！原 12 卷指引指错字段，勘误 10-04）。11 卷组件 1 旧 schema（f2/f3 记为空对象、缺 xyz 子结构）作废，以本表为准。
- 体型缩放：11 卷另记变换组件 f11.4 = f32 档位 0.9/1.0/1.1/1.2/1.3/1.5/2.0/3.0 [K]，与 f48（速查#10）关系待对齐。

### 2. 怪物参数（f6 槽组件 7 → f17）

```
f17 = { 1: f32 视觉感知范围(米), 2: f32 仇恨触发范围(米), 3: f32 脱战时间(秒),
        5: 1, 6: {小配置}, 8-15: f32×8 抗性（火/草/水/雷/风/冰/岩/物理） }
```

- 抗性定量律（实测定拟合 [A]）：伤害倍率 ≈ `0.1/(抗性+0.1)`。默认 0.1=标准半减；免疫怪=写 10；易伤=写 0（人形怪物理 −0.2=易伤，原神惯例）；Boss 高抗=0.7。
- 感知梯队：95.1m 遗迹守卫 ｜ 27m 史莱姆族 ｜ 2.7m 野林猪（被动怪，脱战字段缺省）；脱战普遍 500 秒。
- **93 怪参数表**（内部实测数据，要点已录入本表）：93 条；键=asset_id；值={name, visual_aid, perception(=f17 实值), components}。改怪先按此口径核对再写 f17。

### 3. 颜色与材质

- **字节侧宿主**：f6 槽组件 22 → f32。schema 与编码陷阱（f3≥2³¹ 须按 int32 带符号写 10 字节负数 varint）**见 02 册 §二**，不重复。要点索引：f3=AARRGGBB（高 8 位=覆盖浓度，非实体透明度）；f5=RRGGBB 镜像；f8=1 正片叠底/缺省覆盖；f4=100.0 米交互距离；f6=6700 常量；f9=历史/节点码。
- **官方节点范式** [D]：节点【修改模型颜色和材质】= 目标实体(Ety)/覆写颜色配置/启用自定义颜色/填充颜色(十进制码)/颜色透明度(**0-100 整数**，浮点向下取整)/叠加类型(覆盖|正片叠底)/覆写材质配置/启用自定义材质/填充材质类型(**冰|石化**)。装饰物颜色/材质可被主物件覆写。
- 半透明实体不可由 f3 alpha 达成（alpha=覆盖浓度）——玻璃感需透明形态实体+叠色（11 卷"玻璃三径"）；**不可见** = f6#8/f18 删 `f1:1`（[A·实证案例]，PropertyStaticVisible 实锤）。
- **挂特效**（通用配方 [K]）：f7 槽加组件 → {挂点名("GI_RootNode" 等), 特效模板 id}；特效模板 id 取自内部维护的特效 id 表（约 498 项）。
