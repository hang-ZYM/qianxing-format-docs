# 18 · 编辑器行为定律（查对手方行为）

> 参考册：文件级操作前先查这里——编辑器会怎么反应。
> 完整表述见 docs/02（六条行为定律）与 docs/21（运行时架构）；本册为操作视角速查。

## 一、会话与生命周期

| 行为 | 定律 |
|---|---|
| 生命周期 | = 关卡会话：进关卡拉起、退关卡退出；无常驻进程可依附 [J] |
| 数据入口 | 进关卡时由游戏侧推送进入（连接后数秒完成）；**编辑器不读 .gil 文件** [J] |
| 活画布 | 图打开才有活画布（单文档槽位，一次一张）；未打开的图在序列化态 [J] |
| 图身份 | 图的打开/选择走内容包装层引用链；可见性树为**拉取制**（刷新动作驱动），
  非事件推送 [J] |

## 二、装载行为

| 结果 | 表现 | 机制 |
|---|---|---|
| 接受 | 内容存活 | — |
| 拒收 | 文件被忽略/回滚，**无提示** | — |
| 静默剥离 | 节点/连线被删 | 装载层静默跳过；诱因：kernel 越宇宙(470)/泛型裸值/kind5 缺件 |
| 静默回写 | 内容存活但被规范化 | 重保存对比可反推规则；旧版本号触发导入升级器重写
  （出件写 CNRELWin7.1.0） |

**静默降级律**：编辑器/导入器/运行时三层对内容问题**全部静默**——错误唯一表达
="东西不见了"。

## 三、保存与云端

| 定律 | 操作含义 |
|---|---|
| 保存 = 上行云端 | 本地修改后需在编辑器内保存一次才持久 |
| 进地图列表 → 云端覆盖本地 | 文件修改窗口在编辑器关闭期间 |
| 打开中关卡主 .gil 滞后 | 查状态双查主件 + Temp（Temp 才新鲜） |
| .gia 导入直写云端 | 导入后无需再保存 |

## 四、编辑器侧限制（操作前必知）

- 编辑器 UI 操作（建脚本模板/挂脚本/建容器）**没有自动化通道**——必须人工 [J]
- 编辑器进程内**无实体数据模型**——实体操作走游戏侧通道（01 册）
- 编辑器对图内容的某些整关级操作会破坏其他图内容——操作作用域（画布 vs 整关）
  必须先确认（事故实证）
