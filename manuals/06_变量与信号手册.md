## 一、结构定律

**三层变量（状态放哪）[A]**：

| 维度 | 实体变量 | 图黑板变量 | 自定义变量 |
|---|---|---|---|
| 声明位置 | 实体 f7 槽首组件（f7#1） | 图 f6（GraphVariable 声明池） | 地图主 .gil 顶层 f35 注册表 |
| 作用域（存储轴） | 单实体 | 单图 | 全地图（Lua 可读——双语唯一状态桥）；**运行时再按 API 域轴分裂**，见 §一.5 |
| 寻址 | 变量名（f7#1.11.1 字段 2） | 变量名字符串（运行态按名索引） | 变量名字符串（须先入注册表） |

实体变量（f7#1，编辑器可见中文显示名）：`11:{1:{2:变量名(utf8), 3:类型, 5:值}}`——类型 4=Bool、6=字符串族…（编号表待复核）。图黑板（随图保存）：`{f2:变量名, f3:base_type,
f4:初始值, f5:is_public, f7/f8:容器子类型}`；实测样本："对话交互按钮"{Int, public}、
"选项控件列表"{IntList(8)}、"空列表"{StringList(11)}。自定义变量（f35）[J]：条目按字典序；
**名字不在注册表=运行时读不到**；注册表不可字节级修改（追加合法条目也解析失败），只能
模型级写入或编辑器变量面板创建；新地图注册表为空壳。

**名字明文寻址定律**：黑板变量装载时由 f6 声明池转为按名索引的运行态池，读/写节点拿变量名
字符串寻址（与自定义变量一致）[J]（docs/23 §5）——**变量名是运行时契约，改名=改寻址，引用点必须同步**。

**信号系统（事件怎么传）**：信号=**全局广播消息**，跨实体/跨图/跨服务器-客户端通信的唯一机制；思想是解耦——各实体只处理自己关心的事件、不直接操作其他实体（官方教程）。**声明机制**：沙箱信号管理器配置，信号=`{信号名(字符串), 参数列表(合法类型×N)}`；**按名寻址不按结构**。

**通信矩阵**（docs/15 定案 + 本册补录 3000005）：

| 发送方 ↓ | → 服务器图 | → 客户端图 | → 客户端 Lua |
|---|---|---|---|
| 服务器图 | 节点 300000 | ❌（推理 [P]） | "发送客户端脚本信号"节点 |
| 客户端图 | 节点 200124 | ❌ | 节点 3000005（仅客户端域） |
| 客户端 Lua | `ServerSignal:SendSignal()` | ❌ | 本地调用 |

服务器图是唯一信号中枢（客户端只能上行，服务器向所有端广播）；"❌"三格为架构推理非实拍 [P]，服务器侧"发送客户端脚本信号"节点 ID 未入 docs/07 节点目录，归属待复核。

### §一.5 API 域轴（运行时作用域，与存储三层正交）[A，官方 API 字典（data/client_api.d.lua）]

自定义变量在 Lua API 侧按 `Enum.CustomVariableEntityType` 选域——**同一个变量名，不同域各自一份值**：

| 域 | 值语义 | 适用 |
|---|---|---|
| **Level（关卡域）** | 全地图共享一份（所有玩家同值） | 全局状态：波次/分数/回合 |
| **PlayerSelf（玩家域）** | 每个玩家各一份 | 个人状态：个人得分/背包/任务 |
| **AvatarSelf（角色域）** | 每个角色/化身各一份 | 角色绑定状态 |

API 签名（域为第一参数）：
```lua
game.GetGlobalCustomVariableValue(entityType, customVariableName)
game.SetGlobalCustomVariableValue(entityType, customVariableName, value)
script:RegisterCustomVariableChangedHandler(entityType, customVariableName, cb)  -- 注册须在 OnInit 内
```

**联机含义**：PlayerSelf/AvatarSelf 是联机各自独立的关键机制——个人状态不串号靠选域；
服务器图读写（设/取自定义变量节点族）默认走哪个域**待复核**（节点参数面是否有域选择待查）。

## 三、使用配方

**1. 变量读写落地**：按作用域选层（单实体/单图/全图+Lua）→ 自定义变量先在注册表建名后用 →
黑板改名同步全图引用点 → 感知变化接 36/351 → 一律显式初始化（理由见四）。

**2. 信号收发接线**：信号管理器先声明（名+参数表）→ 发送方 300000（选信号名后入参自动展开，按参数表填值）→ 接收方 300001（Trigger 域只有出流——事件源无入流；出参=参数+三上下文）→ 新增响应方各自加 300001，发送方零改动（解耦收益）。

**3. 图↔Lua 互通**（掉线检测范式）：Lua 心跳 `ServerSignal:SendSignal` → 服务器图 300001 处理 →
写自定义变量 → Lua `Get/SetGlobalCustomVariableValue` 回读（另有变化订阅）；基底用内部维护的
金标准样本关卡（样本库不入本仓库）。

**4. 选型**：

| 方式 | 性质 | 适用 |
|---|---|---|
| 直接操作（A 的图写 B 的变量） | 高耦合（A 必须知道 B） | 两三个实体的简单联动 |
| 信号广播 | 低耦合（只认信号名） | 多实体联动、跨域通知 |
| 变量 | 持久状态 | "是多少"；信号是"变了这件事"（瞬时：发一次收一次） |
