# 09 · 技能与模板库手册

> 任务：理解 f15/f16 模板库结构 → 查模板族 → 写自定义职业/自定义模板 → 定位技能数据。
> 对照：RPG 模板样本图 × 空白样本图（内部实测样本）；定律基准：配置字段号 = 组件 ID + 10 [A]。

## 一、结构定律

| 字段 | 角色 | 规模 |
|---|---|---|
| f15 | 默认模板库：编辑器出厂自带，所有地图（含空白图）均有约 8KB | 5 个子项（RPG 模板实测）[A] |
| f16 | 自定义模板增量：用户在编辑器中添加的模板 | 空白图 0 条；RPG 模板 1 条（91B）[A] |

子项结构（f15/f16 通用）：

```
子项      = { f1: guid, f2: guid(同值), f3/f4: 内容区 }
内容区组件 = { f1: 组件ID, f(组件ID+10): 载荷 }     ← 与实体组件系统同构
```

即"容器+组件"母范式在模板域的复用（模板库/实体/图统一三层架构）。旧认知勘误：早期认知称
f15/f16 为"职业/玩家模板+技能库"——实际是跨域默认模板集合（五族），技能仅是"自定义职业"子项的一部分 [A]。

## 三、使用配方

**3.1 读模板库**：定位 .gil 顶层 f15 → 按槽位/guid 找族 → 按 {组件ID, f(ID+10)} 拆内容区载荷；f16 为空 = 该图无自定义模板。

**3.2 加自定义模板（写 f16 增量）**——RPG 模板实测条目（道具族，91B）：

```
f16.f1 = { f1: guid 0x42000001（0x420=道具段）, f2: guid(同值),
  f3: { f1:39, f49: { f1: { f1:9999, f3:1, f4:4202, f5:4301, f6:引用(5B), f502:1 } } } }
```

该条 39→f49 符合定律，佐证 §一 结构；其 guid 与 f15[4] 相同，疑为对默认条目的自定义覆盖（未判）。
内层数字未定性（9999 疑物品 id，4202/4301 疑道具/图标 id）。新增模板要点：选族段位 guid、避开
图内已用值、按同构结构组装、往返一致性校验后入库。

**3.3 技能藏在哪里**：技能不在 f15/f16 顶层，两条存在路径——

| 路径 | 位置 | 说明 |
|---|---|---|
| 职业内嵌 | f15[2] 深层嵌套（1481B 载荷，结构未判） | 疑技能列表/属性面板 |
| 编辑器独立管理 | 技能编辑器（"战斗预设"页签）单独编辑后引用进职业模板 | 技能是被节点图技能节点调用的独立资源 |

官方关键数字（**官方文档口径，未核定**）：职业可配置技能上限 50｜自定义技能最大数量 1000｜技能资源数量上限 2000｜技能动画数量上限 100——技能是大型独立子系统，非 .gil 单字段。
