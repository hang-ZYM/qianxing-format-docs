# 07 · 控制流与运行语义手册

> 任务：看懂图的执行语义、正确使用控制流、预判运行时行为。
> 读完本册可回答：图跑起来按什么顺序发生什么、哪条连线合法、怎么读到真实执行。

## 一、执行模型：五类节点流水线

| 类 | 数量 | 流引脚 | 语义 | 角色 |
|---|---|---|---|---|
| Trigger | 57 | 只有出流 | 事件源，图的**唯一执行入口** | 碰撞/定时器/变量变化/信号/实体创建… |
| Query | 174 | 无流 | **被引用即求值**（Pure，不占执行位） | 取数据 |
| Arithmetic | 101 | 无流 | 同上 | 判定/运算 |
| Control | 3 构型 | 入+出流 | 条件路由/迭代（§二） | 控制流转 |
| Execution | 203 | 入+出流 | 把结果写回世界 | 设变量/控实体/播音效/切界面 |

执行语义（"事件→查→判→做"四段式）：①事件驱动点火 ②惰性求值 ③顺序流转（一个
FlowOut 可连多个 FlowIn=广播，语料实际罕见 2%）④条件路由 ⑤迭代 ⑥状态落地。

- **同帧时序**：同帧多事件顺次执行且时序固定——确定性排队而非并发竞态，同构输入必得同构输出 [J]。
- **执行链长度**（131 图语料）：平均 5.4 步、中位 6、最长 23，多数逻辑五到八步收束 [A]。
- **结构化定论**：无 while、无 goto、无协程/await（同步执行）、无递归（词表无自图调用机制）[J]；一图的执行是原子的，不被另一图打断（单线程语义）。
- 口径注：五类分项合计 555 vs 节点总数 558（Hidden 17 未入流水线，既有卷宗分项待核）。

## 二、控制流节点全表

**口径声明**（既有卷宗三套计数并存：3+1／5 行／3 构型，本册统一）：按**构型**计数为
**3**（条件／迭代／中断）；全表 **5 节点行、7 个 ID**（有限循环、跳出循环各有新旧
双 ID）；§一"Control 3 个"即构型数，非行数。

| ID | 名称 | 构型 | 流引脚 | 数据引脚 |
|---|---|---|---|---|
| 2 | 双分支 | 条件 | In + True/False 双出口 | cond(Bol) |
| 3 | 多分支 | 条件 | In + Default + Case1-9 十出口 | key(R\<T\>)入 + cases(L\<R\<T\>>)入 |
| 5/200079 | 有限循环 | 迭代 | In + Iteration/End 双出口 | start/end_index(Int)入 + current_index(Int)出 |
| 509 | 列表迭代循环 | 迭代 | 同上 | list(L\<R\<T\>>)入 + item(R\<T\>)出 |
| 6/200080 | 跳出循环 | 中断 | In + Out | 无 |

**多分支泛型**：仅 T:Int 与 T:Str 两变体（枚举本质是 Int，故覆盖枚举匹配）；key=控制
表达式、cases=候选值列表，与 switch-case 同构——生成器不要生成其他类型的 cases。

**真实图用法**（131 图 3497 实例语料 [A]）：True 出口 Top 为嵌套双分支 54／多分支 20，False 出口 Top 为设自定义变量 30——嵌套分支（分支→分支）合计 64 次=主流用法，True 偏深入判定、False 偏写默认状态；循环仅 18 实例（列表迭代 13＋有限 5）vs 分支 311 次，**分支:循环≈17:1**——关卡逻辑以条件判定为主、迭代为辅。

## 三、运行语义定案（全部 [J]，出自 2026-09-30 运行时实证批次：多组同局试件，执行记录逐条核对）

**求值规则**：运算流跟随执行流——Query/Arithmetic 在执行流到达引用点时才求值，不是开图全算；跨执行流引用取该查询**前一次执行的值**（可当缓存变量用）[J]。
**无值变量=默认 0**：未赋值变量行为与 0 一致（实测 0>-1 走真分支）——数据依赖必须排在执行依赖之后，否则读到 0 [J]。

**有限循环**（试件：循环 3 次、连跑 6 轮）：

| 语义点 | 实测 [J] |
|---|---|
| 迭代次数 | 精确=参数，不多不少，无 off-by-one |
| 端语义 | 区间 **1..N 含两端**（start/end_index 都取到） |
| 轮内时序 | 循环体按执行线顺序；Iteration 出口逐轮触发，End 出口最后触发一次 |
| 跨轮一致性 | 6 轮全同构，循环变量每轮重置，无状态残留 |

**多分支**：key 与 cases 按值匹配，命中 Case N 从 N 出口流出（实测 case3 六连命中、
零走默认）；全不中走 DefaultBranch；只支持 Int/Str [J]。

**黑板变量运行态**：编辑态 f6 声明池 →(图装载)→ 运行态变量池（按名字索引），读写节点按变量名字符串寻址；实测六轮"读→改→写回"全一致，f21 明细变量名与运行时值逐条可见 [J]。**变量名是运行时契约——改名=改寻址，所有引用点必须同步。**

**强类型→泛型连线**：泛化方向（concrete→generic）合法——循环 current_index:Int 可
直接传入泛型入参 [J]。**注**：连线侧值仍须物化 **poly 信封**
（{widget10000+f110{f2{actual}}}），裸形态被装载层剥除（开图丢线第一嫌疑）
[A]；反向 generic→concrete 需类型已决议。

**实体寻址与信号**：图挂实体后事件内"本实体"寻址运行时正确解析 [J]；Lua
信号处理器注册必须在 OnInit 内，晚注册收不到已发信号 [J]；客户端只能向服务
器发信号，双向设计靠服务器中转（通信矩阵见 docs/15）。

## 四、观测方法：怎么读到真实执行

图执行记录**写入链**（对"本地落盘"这一无条件断言的完整限定，详见 17 册）：运行时 →
传输 → **编辑器收集器** → 落盘。四条硬约束：

| # | 约束 [J] | 误读陷阱 |
|---|---|---|
| 1 | 编辑器是写入者，**游戏内直接试玩=零 .gia** | 零文件≠未执行 |
| 2 | **勾选监听制**：编辑器节点图日志筛选须勾选目标图（服务器图上限 10/客户端 99） | 未勾=零文件，与脚本是否执行无关 |
| 3 | 勾选**每会话归零**，每轮重勾 | 沿用上轮勾选必漏采 |
| 4 | 两层门：总开关门控脚本 print，树勾选门控节点图执行记录 | 只开总开关看不到图明细 |

三层观察面：图执行记录（节点触发／变量名与运行时值 f21／连线数据流）｜客户端脚本日志（Lua print 全量）｜运行时局内存档 .gir（试玩世界状态快照；卷间定义尚未统一，引用时注明口径）。

标准操作=差分采集协议（详见 17 册）：试玩前记录基线（各观察面文件清单/最后修改时间）→
用户试玩 → 试玩后差分三件套（新 .gia 执行条目＋output_log 增量＋新 .gir）。基线/差分的
批量采集工具由项目内部维护，不在本仓库，手工记录同效。纪律：单变量原则＋预写判据（试玩前明确"看到 X=判 Y"）。

**生成器守则速查**：数据依赖排在执行依赖之后（防读到默认 0）｜cases 只给 Int/Str｜循环上界显式（无 while）｜泛型入参一律 poly 信封｜变量改名全图同步｜逻辑 5-8 步收束。
