# 15 · 资产包手册（.gia）

> 任务：把一批实体打包成官方资产组合包 → 游戏内导入。

## 一、数据资产

| 资产 | 位置 | 用途 |
|---|---|---|
| 基础转换器 | 内部维护（本仓库不含） | .gil 实体区 → .gia 最小实现（教学参照：容器结构与实体包装写法） |
| 批量构建器 | 内部维护（本仓库不含） | 设计文档 → 合成 → staging .gil + 双包（全量 + 区域小包） |
| 官方导出样本 | 游戏本地 `BeyondLocal` 目录下的导出子目录（官方导出通道产物） | 历史包与官方件参照 |
| 实测记录 | docs/27 §6 | 三批（207/258/264 件）判决 |

## 二、格式规范 [A，逆向 + 三批实测]

```
Container（type=3）:
  f1 × N: 实体包装 {
      f1: 引用 {f2:1(类型=实体), f3:2(子类型), f4: guid}
      f3: 实体显示名（UTF-8）
      f5: 3（常量）
      f12: {f1: 实体完整字节}     ← 与 .gil 实体消息同构（02 册规范）
  }
  f3: 元数据 "账号-时间戳-地图id\\文件名.gia"（时间戳=unix 秒）←⚠元数据含账号与地图 id，
      对外分享自建包前注意其为个人标识
  f5: 版本 "7.1.0"
```

实体字节携带位置/缩放/旋转（度）/染色全部参数——导入后原样生效 [J，三批确认]。

## 三、操作配方

**批量出包**（设计文档驱动；批量出包工具内部维护，本仓库不含——步骤与字段规范如下，可据此自行实现）：
```
设计表（02 册四的行格式）→ 解析（弧度→度 / 镜像 / ±简写 / 紧凑行 / 染色族映射）
→ 逐件合成（guid 连续分配 0x404 段，先全档扫描防撞）
→ 滤地图默认实体（关卡实体等 11 件，防导入重复）
→ 包装（元数据写目标地图 id；版本 7.1.0）
→ 往返一致性校验 → 落盘 .gia
```

**导入（用户操作，2-3 次点击）**：游戏内资产导入界面选文件 → 确认 → 实体进图。

## 四、真实工作例

**例：264 件全量包**（2026-10-04）——设计文档 264 行 → 合成零失败（染色 120 件）→
`防守据点_模块包_v3.gia`（160KB）。字节级抽验：石墙 f3=0x308F8A7C（暖灰叠底）、
旗帜 f3=0xC035528F（覆盖式，10 字节符号 varint 路径正确）。

**例：区域小包**——同管线只导出某 guid 段（如某区域 32 件）→ `主城_v2.gia`。
区域化配合逐区域迭代：一包失败不污染已验收区。

## 五、通道行为速查（判例）

| 行为 | 结论 |
|---|---|
| 导入位置 | 游戏内（编辑器内导入不了） |
| 撤回 | **无官方撤回**——导入直写云端存档；撤销=编辑器框选删除或 .gil 手术 |
| 迭代 | **同 guid 重复导入行为未判（开放问题）**——决定小步重导还是先删后导，下批导入前必判 |
| 上限 | 件数/字节上限未测（开放问题） |
| 云端互动 | 导入后内容入云端；本地 .gil 与云端的分叉处置见 16 册 |
