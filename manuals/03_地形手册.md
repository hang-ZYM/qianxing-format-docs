# 03 · 地形手册

> 任务：改地形——层位/坡/材质/水/路径/组。走 .gil 文件级修改（编辑器关闭时）。

## 一、字段规范

地形存于 .gil **f7** → 组列表 → 每组 {f1:组id, f2:名, f4 × N: 地块}。
地块键 = `(grid_x << 16) | grid_z`（grid 100~119）。

| 字段 | 含义 | 值 |
|---|---|---|
| f1 | 格键 | (gx<<16)\|gz |
| f2 | 层位 | 1/2/3；**省略=1** |
| f3 | 材质 | 1 冰/4 草/5 混拼/6 岩…（八色） |
| f4 | 水体 | 1=顶面水（坑式：水底 L1 + 岸抬 L2） |
| f5 | 路径表面 | 1 |
| f6 | 坡 | `16×型 + d`（d: 0东 1南 2西 3北）；坡块层位=低侧层位 |

**格网模型**：5m 一格、2.5m 一层；空白图 20×20 = 400 格（上限 200 格边长）。
**格位↔世界坐标**：`tile = (x/5+9.5, z/5+9.5)`；格 (i,j) 占 x∈[(i−10)×5,(i−9)×5]。
层高对照：L1=0 / L2=2.5 / L3=5.0 / L0=−2.5（壕沟河床）。

**两条结构铁律**：
1. **坡与水/路径互斥**（同格不同设）；**引擎坡=楼梯**（无平滑斜坡）——地形设计的
   根本约束
2. **地块列表是整体替换，不是增量合并**——只写"变化块"会把其余块丢成虚空 [J，
   2026-10]；写入前必须对账底座块数，或全量写入

## 二、操作配方（程序级步骤）

```
① 确认编辑器已关闭（16 册时序协议）
② 备份目标 .gil
③ 保序解析 → 定位 f7 组列表 → 目标地块
④ 修改字段（set 层位/坡/材质/水/路径 = 改对应 fN 值；删坡 = 移除 f6 字段）
   · 新增地块：按字段序构造 {f1:键, f2:层位, [f3材质], [f4水], [f5路], [f6坡]}
⑤ 重编码 → 往返一致性校验
⑥ 回读验证（块数对账 + 抽查）
⑦ 用户重进图 → 装载目检
```

**设计网格语法**（可自建）：以字符画描述全图（`.`草L1 `#`丘L2 `M`山L3 `s`石台
`S`石面 `x`壕 `X`河床 `/`坡 `~`路径），再按格转换——保证全量写入不缺块。

**层位审计**：落地实体 y 必须等于所在格层高（草 0/台 2.5/山 5.0）——按格位映射
逐件核对。

## 三、真实示例

**示例：镇北水道三处修改**（一次通过的实战）
- 铲平门口台阶：两格 set_layer(…, 1)（原 L2 岸块造成布景穿模）
- 拆坡：删除两格的 f6 字段（保留层位）
- 挖水道：两格设 f4=1（水底 L1 + 周岸保持 L2）

**坑式水体**：水格层位 1 + f4=1；相邻纯草格抬 L2 作岸——这是水体推荐的物理形态
（避免"平面悬水"）。

## 四、常用值速查

| 操作 | 字段写法 |
|---|---|
| 升一层台地 | f2=2（L3=3） |
| 东向楼梯坡 | f6=16+0（南 16+1 / 西 16+2 / 北 16+3） |
| 河床 | 层位 1 + f4=1 + 岸抬 L2 |
| 巡逻路皮 | f5=1 |
| 换材质 | f3=目标色（1-8） |

多组机制：f7 支持多组并存（多笔刷岛）；同键跨组 = 有意堆叠；空格 = 虚空。

**设计基线**：人工区=直（平台/壕沟/广场保几何），荒野区=曲（起伏成簇非孤包）；
层位过渡三原则——路径经过的过渡必须有坡覆盖；玩家可跌入的凹陷必须有出口坡；
垂直面只留给"永远不该被走"的表面。

**开放问题**：水道的可通行性（游泳/阻挡行为未验证）。
