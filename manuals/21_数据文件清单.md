## 四、使用要点

- 查实体占地 → `prefab_sizes_full.json`（02 册配方的前提）
- 写 Lua 前查 API → `client_api.d.lua`（可直接 attach 给 IDE 得补全）
- 选节点 → docs/07 + docs/13（使用率与搭配）
- 出图基底 → templates/ 三件（QUICKSTART 十分钟路径）
