# 04 · 节点图手册

> 任务：构造玩法图（服务器图/客户端图）——合成、装配、离线校验。

## 一、数据资产

| 资产 | 位置 | 用途 |
|---|---|---|
| **模板三件** | 本仓库 `templates/`：default_graph（190B 最小图）/ dialogue_chain（对话链）/ branch_loop_vars（12 节点构型全集） | 合成基底（QUICKSTART 十分钟路径即用） |
| 节点全典 | docs/07 | 558 节点选型查询（功能/引脚/参数/变体） |

原生节点字节样本库与图装配工具由项目内部维护；本手册给出结构与校验规则，
简单图用模板合成即可（qxfmt compose），复杂图按 §三 路线 B 的规则自行装配。

## 二、结构与字节规范

**结构四元组**：节点（kernel+参数）/ 引脚（kind,index 寻址；流/数据/泛型三类）/
值（TypedValue）/ 连线。

**连线编码**（方言统一 [A，2026-10]）：

```
执行边：存【源】引脚 f5 = {f1:目标节点, f2:{f1:1}, f3:{f1:1}}
数据边：存【目的】输入引脚 f5 = {f1:源节点}（kind 4→4）
——服务器图与客户端图一致，生成器两边通用
```

**泛型信封（铁律）**：泛型槽位值必须包 poly 信封
`{widget10000 + f110{f2{actual{真实类型}}}}`——裸形态被装载层静默丢弃
（"开图丢线"的第一嫌疑）。

**kind5 属性引脚正典**：完整形态 = f3 值 + f6{1:6,2:1} 标记 + f7，三者缺一即 SICK。

**图头**：field1=10000（非 10001）；图 guid 取 0x40000000 段空号；版本 CNRELWin7.1.0。

**变量三层**与**信号系统**：见 06 册；**控制流与执行语义**：见 07 册。

**双语分工**：服务器图=权威状态机；客户端图（决策/状态/技能）挂复杂造物驱动 AI；
互通走 3000005 信号节点（**仅客户端域**，入服务器图会级联剥除 [J]）。

## 三、操作配方

**路线 A：模板合成**（简单图——本仓库 qxfmt 原生支持）：
```bash
python -m qxfmt compose -t templates/default_graph.gis -o my.gis --text "你好" --guid 0x40000030
python -m qxfmt verify my.gis
python -m qxfmt roundtrip my.gis
```

**路线 B：标本装配**（复杂图——规则如下，可自行实现）：
```
① 取原生节点字节样本（编辑器原生创建的图，保序解析提取）
② 克隆节点 → 重排节点 ID/坐标 → 修改参数值
③ 清除样本自带的连线（源引脚 f5），按 §二 连线编码重新连接
④ 泛型入参物化 poly 信封骨架
⑤ 图头（field1=10000 / guid / 版本号）→ 重编码 → 往返校验
```

**校验链**（出件必过，前两层本仓库可用）：
```
python -m qxfmt verify <file>     # 规则面：kind5 正典/信封完整/基本形态
```
装载级确认：官方导入后观察存活（docs/06 §10 的差分方法）。离线规则校验通过
≠ 装载通过——权限边界见 17 册。

## 四、真实示例

**最小可跑图**（模板解剖定案）：kernel 71（实体创建事件）→ kernel 1（打印），
