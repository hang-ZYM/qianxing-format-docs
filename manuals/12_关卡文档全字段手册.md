## 二、独立文件族（地图目录）

| 文件/目录 | 是什么 | 类型码 / 位置 | 谁读写 | 级 |
|---|---|---|---|---|
| `local_setting.gils` | 地图本地设置 | 容器类型码 8【待复核】 | 编辑器写、随地图分发 | [J] |
| `external_lua_file/` | 客户端 Lua 脚本目录 | 地图目录下 | 与服务器图经信号系统互通 | [K] |
| `.gilh` | 地图实体索引：地图名+实体摘要表（guid/分组/名称） | 容器 806 族 | 编辑器地图列表/实体枚举缓存【归属待复核】 | [J] |
| `.gir` | **已发布关卡的服务器运行时数据** | `Beyond_Local_Save_Runtime`，按发布 id 存放 | 服务器侧 | [K] |
| `RuntimeCustomAssetPack` | 自定义资源包本地缓存（商城/导入资产） | 地图目录下 | 客户端 | [K] |

`local_setting.gils` 结构：`{f1:地图id, f2/f3/f4:设置串(如"PropertyTransform"配置), f5:协作分区配置(联机关卡含"协作部分_1..N"分区名表), f6:时间戳, f7:属主玩家uid ←⚠个人标识：对外分享/入库前必须脱敏, f8:地图id}`

**.gir 异说**：docs/23 作"试玩快照"、docs/10 作"已发布关卡运行时数据"——本册采信 docs/10 定义，待原档复核后统一（2026-10-04 验证发现）。

双语分工：服务器图（f10 内 0x4002xxx 段）管逻辑判定，客户端 Lua（`external_lua_file/`+f50）管表现/界面；互通走 `SignalSignature{signal_name, server_node_id, client_node_id}`，**Lua 侧信号注册必须在 OnInit 内**（详见 06/14 册）。

## 四、装饰物与特效

- **装饰物**走 .gia 通道（打包/导入见 **15 资产包手册 gia**）：`DecorationItem = {name, template_id, pos, scale, yaw_deg}`——**yaw_deg 旋转单位=度**；实体侧挂载 = f5 行为槽 type14 子物体 + type40 子实体引用（槽表见 02 册）。
- **特效** [K]：实体 f7 槽组件 → `{挂点: GI_RootNode, 模板 id}`；受击/倒地特效钩子 = f7 槽 comp18；特效模板 id 库 498 个已枚举。
- **音频**：f22 注册 `PropertySoundEffect` 属性类后实体可挂音频属性；f50 实测含 `game.PlayAudio2D(1001)` 客户端调用 [A]；独立音频/BGM 域存在性待确认。

## 五、UI 布局库（f9）速览

暂无专册，记本册。首攻三轮定案（2026-09-29）[A]：

- f501 = 模板 guid 注册表（135B 裸 varint 序列，27 个 guid，**不是 protobuf**）；f502×N = 控件实例（实测 189 件/102KB）= {f501 实例guid, f502×N 子组件引用(395), f504 模板guid(29 种), f505×N 内容/覆写块(677, 占 87% 字节)}
- 实例层 f503×29 = guid 区间对（分配窗口）；内容块 = {f11-f28 属性槽, f501+f502 (键,值) varint 对}，内嵌 f503 = 嵌套绑定记录 ×446——`{1:ps.变量}` 表达式原文在此；0x40000001 = 系统根 id
- **模板定义不在 .gil 里**：29 个模板 guid 仅现于 f9 内部（追踪零外部命中，仅 2/27 与 f10 重叠且为系统根）→ 控件模板是**编辑器内置类型系统**（同实体与 prefab 的关系：.gil 只存"哪个类型放在哪+覆盖值"）
- 声明式 UI：控件树+富文本模板 `<color=#FFCC33>`+数据绑定 `{1:ps.变量名}`（列表索引 `{1:ps.名.N}`、动态色 `<color=#{1:ps.titleColor}>`）——直连地图自定义变量系统（06 册）；平台禁自定义图片上传（imageId 只读，仅官方图库+真实 NPC 模型）
- **开放问题**：模板定义的存放地（非 f8 元件库、非实例层 f503）
