# 19 · 排障判例库（按症状查）

> 参考册：出问题了先查这里。症状 → 根因 → 处置。

## 一、实体与布景症状

| 症状 | 根因 | 处置 |
|---|---|---|
| 导入后旋转全部失效（墙不转向） | **旋转单位是度不是弧度**——π/2=1.5708 被读作 1.57° [J] | 传 90.0/180.0/-90.0；上游 schema 字段名即 yaw_deg |
| 布景位置整体错半格 / 压在台上 | 格位映射错——正确 `tile=(x/5+9.5, z/5+9.5)` [J] | 按公式重算；落地 y=格层高 |
| 摆件穿模/悬空 | 地形有隐形台阶（自动抬升的岸块）；或 y 未按层高 | 先查地形数据再动手；y 规则见 02 册 |
| 实体不渲染 | guid 段位错（机关须 0x404；怪物 0x408） | 换段重合成 |
| 染色不生效 | 开关簇 {f1,f2,f7} 缺一；或参数序传反 | 补开关簇；序=(rgb24, alpha, blend) |
| 染色值污染后续字段 | f3≥2³¹ 未走 10 字节符号 varint | 用 int32 带符号写法 |
| 摆件互相穿插 | 未查 W/D/H 实测表（直觉估尺普遍偏小） | 查尺寸表；三维 AABB 审计 |
| 官方门/桥挡不住怪 | 官方模型 = 无碰撞装饰件 | 组件自拼（碰撞开关效果为开放问题） |

## 二、地形症状

| 症状 | 根因 | 处置 |
|---|---|---|
| 大片地图变虚空 | **地块列表整体替换**——只写变化块丢其余 [J] | 对账底座或全量写 |
| 地形割裂感强 | 引擎坡=楼梯（无平滑坡） | 台地化设计+实体贴面软化 |
| 坡格设了水没反应 | 坡与水/路径互斥 | 分格设 |

## 三、图症状

| 症状 | 根因 | 处置 |
|---|---|---|
| 开图丢线 / 分支口全无连线 | 泛型入参裸形态缺 **poly 信封**（第一嫌疑） | 包信封 {widget10000+f110{f2{actual}}} |
| 节点消失级联断线 | kernel 不在宇宙（470） | 查节点全典确认 kernel 合法 |
| 规则校验报 kind5 问题 | kind5 缺三件套之一（f3 值+f6{1:6,2:1}+f7） | 补全正典形态 |
| 服务器图含 3000005 被剥 | 3000005 仅客户端域 | 移出服务器图 |
| 图导入被重写 | 版本号旧（7.0） | 出件写 CNRELWin7.1.0 |
| 离线校验通过仍被剥 | 离线权限边界（四类异常只有活体能裁） | 活体装载终审 |
| 泛型换类型后值丢失 | 五件套只改了 1-4 没改值存储（**值随型走**） | 五处齐改（05 册） |

## 四、脚本与运行症状

| 症状 | 根因 | 处置 |
|---|---|---|
| 试玩零 .gia 文件 | **编辑器是日志写入者**——游戏内直接试玩无收集器 | 在编辑器内试玩；或本就未执行 |
| 节点图无执行日志 | **勾选监听制**未勾选目标图；勾选每次会话重置 | 每轮重新勾选 |
| Lua 收不到信号 | 注册晚于 OnInit（时序判例） | 移到 OnInit 内 |
| 输出乱码/首字符异常 | BOM（字节顺序标记）问题 | 检查出件编码 |
| 变量行为怪 | 无值变量=默认 0（0>-1 走真分支） | 预期初始化 |
| 联机个人状态串号 | 自定义变量 API 域选了 Level（共享） | 换 PlayerSelf/AvatarSelf（06 册域轴） |

## 五、文件与通道症状

| 症状 | 根因 | 处置 |
|---|---|---|
| 本地修改消失 | 进列表触发云端覆盖 | 文件修改守窗口期（16 册协议） |
| 查关卡状态不对 | 主 .gil 滞后 | 双查主件 + Temp |
| 写入被锁 | 编辑器运行中 | 关闭编辑器再写 |
| 修改无效但无报错 | 嵌套修改漏一层重编码（静默失效） | 每层编码后重新解析验证 |

## 六、流程症状（协作层）

| 症状 | 根因 | 处置 |
|---|---|---|
| 批量产出大面积返工 | 未先验证假设就量产 | 先探针后量产（≤30 件/区） |
| 审查者跟不上修改 | 自动修复轮次过多不可见 | ≤2 轮必停交人看 |
| 目检发现问题比工具早 | 目检是最高效的判例来源 | 人负责"不对劲"，工具负责"为什么" |
| 拿旧结论办新事 | 结论有上下文限定（通道/版本/前提） | 每结论记住成立前提 |
