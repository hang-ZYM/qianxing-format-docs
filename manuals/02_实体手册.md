# 02 · 实体手册

> 任务：查实体 → 合成实体（位置/缩放/旋转/染色）→ 放进关卡。
> 读完本册即可完成实体布景的全部操作。

## 一、数据资产

| 数据 | 位置 | 规模 | 键结构 |
|---|---|---|---|
| **W/D/H 尺寸表** | 本仓库 `data/prefab_sizes_full.json` | 2240 条（91% 覆盖） | 键 = asset_id；值 = {name, mesh, W, D, H}——**单位米，scale=1 原始尺寸** |
| 网格包围盒 | `data/beyd_mesh_bounds.json` | 2771 | 键 = mesh 名 |
| 实体全目录 | docs/08（分类章节） | 2466 项 | 按分类成章（asset_id/名称/类型） |

实体目录的结构化 JSON 与官方 prefab 模板库（2473 条）由项目内部维护，不随仓库发布；
本手册给出全部字段规范与合成步骤，读者可据此用任意保序 protobuf 工具（如本仓库
qxfmt 的 pbtree）自行实现合成。

**查实体流程**：按名称在目录中查 asset_id → 查尺寸表算占地 → 选 guid 段位（§五）。

## 二、实体字节规范

顶层字段（.gil f5 实体区与 .gia f12.f1 同构）：

```
f1  = guid（varint，段位见 §五）
f2  = {f1: asset_id, f2: 1}
f5 × N = 行为组件（名称组件: f1=1, f11={f1:名称UTF8}；模板空名时填官方名）
f6 × N = 编辑器组件（位置组件 comp1 见下；染色 comp22 见下）
f7 × N = 资源组件（挂点/受击特效/实体变量）
f8  = asset_id（varint）
```

四槽语义：f5 行为 / f6 编辑器 / f7 资源 / f8 表现引用。组件定律与高频组件见 08 册。

**位置组件（f6 槽，f1=1）**：

```
{f1: 1, f11: {
    f1: {f1:x, f2:y, f3:z}   ← 三个 fixed32 float；y 整体省略 = 贴地
    f2: {f2: yaw}            ← 旋转，单位【度】
    f3: {f1:sx, f2:sy, f3:sz} ← 缩放
    f501: -1                 ← 模板默认标记，保留
}}
```

**染色组件（f6 槽，f1=22，f32 四件套）**：

```
f32 = { f1:1, f2:1, f7:1,          ← 开关簇，缺一不生效（模板默认无）
        f3: AARRGGBB,              ← 高 8 位=覆盖浓度
        f5: RRGGBB,                ← 镜像
        f8: 1 }                    ← 1=正片叠底；省略=覆盖
```
编码陷阱：f3 ≥ 2³¹（如 0xC035528F）必须按 int32 带符号写 10 字节负数 varint。

## 三、合成配方（程序级步骤）

**前提**：取得目标 asset_id 的官方 prefab 模板（编辑器内置模板库的字节，由内部
工具链提取；模板 = 完整组件树，自带出厂默认值）。

```
① 从模板解析出组件树（保序解析）
② 定位 f6 槽 f1=1 的位置组件，按 §二 结构填充：
   f11.f1 位置三元组（贴地则整体省略 f11.f1.f2）
   f11.f2 旋转（度！90.0/180.0/-90.0，不是弧度）
   f11.f3 缩放三元组
③ （可选）染色：在 f6 槽找/补 f1=22 组件，按四件套写入
④ （可选）f5 槽名称组件填显示名
⑤ 顶层：f1=新分配 guid（0x404 段，先全档扫描防撞）；f2={f1:asset_id, f2:1}；f8=asset_id
⑥ 重编码 → 往返一致性校验（重解析字节一致，否则拒绝）
⑦ 装入目标：追加到 .gil f5 实体区（[1,2,实体字节] 列表项），或打 .gia 包（15 册）
```

## 四、真实示例

**示例 1：金属地板基座**
asset_id=20002056（金属地板，W6.2×D2.1×H8.9）→ 缩放 (10,1,10) = 62×21m 基座；
位置 (0,0,0)、旋转 0、guid 取 0x404 段空号。

**示例 2：染骑士团蓝的旗帜**
asset_id=20002673（旗帜，W6.1×H10.0）→ 位置 (12.6, 6.5, 17)、缩放 0.9、
旋转 -90°、染色 (0x35528F, 0xC0, 覆盖式)——0xC0 浓度触发符号 varint 路径。

**示例 3：复杂造物激活**
见 08 册 §造物——"雕像"根因是 AI 图绑定组件（type80）出厂空槽，激活 = 补绑
客户端图 guid。

## 五、常用值速查

**guid 段位**：0x400 路径｜**0x404 机关（合成主用）**｜0x408 怪物+客户端图｜0x40c 系统｜
0x414 关卡实体（避开）

**落地 y 规则**（格位映射 `tile=(x/5+9.5, z/5+9.5)`，格 5m）：
草/路径/广场=0｜丘/岭/平台=2.5｜山地=5.0；悬空件显式 y；挂装件（招牌/旗帜/垛冠）
不受格位约束

**常用染色配方**（rgb24, alpha, blend）：
暖灰石墙族 `(0x8F8A7C, 0x30, 1)`｜木构深棕 `(0x6B4E33, 0x2C, 1)`｜门/残石冷灰
`(0x7C88A0, 0x28, 1)`｜骑士团蓝旗 `(0x35528F, 0xC0, 覆盖)`｜战旗红 `(0xA03A3A, 0xC0,
覆盖)`｜丘丘压暗 `(0x4A4038, 0x1E, 1)`

**行为边界**：官方门/桥等模型为无碰撞装饰件（可穿行）；功能结构建议用基元自拼
（柱+板+栏）；放样必查尺寸表（灌木实际 4.6m、岩石 7m——直觉估尺普遍偏小）。

**开放问题**：俯仰/翻旋旋转（旋转消息 f1/f3 语义未验证）；静态碰撞开关的实际挡怪效果。
