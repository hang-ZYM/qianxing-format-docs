> 任务：写客户端脚本 → 挂进关卡 → 迭代 → 看输出。

## 二、规范

**载体**：关卡文档 field 50 脚本表（wire 层全解码）；脚本 ID 域 0x4000 段。

**沙箱（Lua 5.3）**：禁 `io.*` / `coroutine.*` / `string.dump` / `os.*`（留 time/date/
clock/difftime）/ `debug.*`（留 traceback）；补 `math.isnan/isinf`。**事件驱动，无同步等待**。

**生命周期七钩子**（运行时按固定名查找调用）：
```
OnInit / OnStart / OnEnable / OnDisable / OnUpdate(不受时停) / OnLevelUpdate(受时停) / OnDestroy
```
传送/重连时控件全销毁，恢复逻辑自理。

**与服务器图互通**：
- Lua → 服务器：`ServerSignal:SendSignal(signalName, params...)`
- 服务器图 → Lua：信号节点 → `script:RegisterServerSignalHandler(signalName, callback)`
  ——**注册必须在 OnInit 内**（实测判例 [J]：晚注册收不到信号）
- 共享状态：自定义变量（Get/SetGlobalCustomVariableValue + 变化订阅，三 scope）
- 联机下行延迟 ≥100ms（官方口径）

**UI 规则**：动态建控件 `game.InstantiateClientUIControl(prefabIndex, parent)` 仅模板
父节点下可用；TextBox.text 可写；容器开 `showCursor` = 纯鼠标 2D 玩法；**两套 UI 隔离**
——服务器控件（旧体系）模板索引 Lua 拿不到；UI 渲染一律走客户端控件（服务器控件
Button/Toggle 有平台 bug：选项文字空白）。

## 三、操作配方

**产出六步** [J，平台级实证]：
1. 取 7.1 基底（可运行样本关卡或自建存档）
2. 替换/新增 field 50 条目（lua 明文写入，varint 长度重算）
3. 控件树属性键 64/74 的脚本引用指向新映射 ID
4. 顶层 field 1 保留基底原值
5. 尾部版本字段写 `CNRELWin7.1.0`（旧版本号触发升级器重写）
6. 离线验证 → 官方导入

**日常迭代**：活文件热替换——直接改 `external_lua_file\*.lua`，免重新导入（外部社区项目
dsh 的部署协议即做此事，本仓库不含该工具）；注意完全退出游戏才落盘。结构变更才走六步重出。

**验证**：导入后按 17 册观察面判读——新 .gia 文件无生成 = 脚本未执行或无输出。

## 四、真实工作例

**基底法**：以可运行样本关卡为底座 → 改 f50 条目为自己的脚本 → 控件键 64/74 指到新 ID →
出件导入。本项目五个示例脚本（hello/hud/announce/settle/dialogue，API 逐函数核对零幻觉）
即此法产出——**注意其量产挂载路径为开放问题**：hello 类脚本出件导入后是否产生输出，
需一次带监听的试玩判定（观察面见 17 册）。

**防御性写法**（项目脚本统一约定）：全部回调包 `pcall`；`print` 观测点前置；
CFG 校准位集中配置。

## 五、速查

| 项 | 值 |
|---|---|
| 挂载键 | 控件树属性键 64（脚本引用）/ 74 |
| ID 域 | 0x4000 段 |

| 注册窗口 | OnInit 内（硬约束） |
