# 10 · 路径与巡逻手册

> 任务：给怪物/巡逻行为做路径——放路点、建路径对象、巡逻引用。

## 一、结构定律

| 定律 | 内容 | 证据 |
|---|---|---|
| 段位 | 路径对象走 **0x400 段** guid（实测 0x40000001-06、0x40000010） | [A] |
| 路点 = 引用实体 | 路点不是坐标，是**引用一个实体**（aid=1000000 路点实体，带位置） | [A] |
| 组件定律适用 | 路点实体 comp1→f11（命名）、comp54→f64（路点列表）——配置字段号=组件ID+10 | [A] |
| 树形组织 | .gil 顶层 f32 = 路径库 → f1 路径对象（树形，实测语料 4900 叶） | [A] |

路径对象字节结构（docs/19 §2 定案）：

```
路径对象 = { guid, name, waypoints: [ {f1: 实体索引, f501: 顺序号} ] }
```

## 二、路点与引用速查

| 项 | 读法 |
|---|---|
| f1 实体索引 | 指向实体列表的 0 基序号——**引用按序号不按 guid**（本册最易错点） |
| f501 顺序号 | 该路点在路径中的次序 |
| 路径共享 | 多条路径可共享同一批路点实体 |
| 实测样本 | 内部样本图：5 条路径；被引实体含出生点 0x41000001、路点标记 0x40c00002/03 |

**易错点**：追加路点实体到 f5 后，其引用索引 = 追加后的列表序号——先记录再引用；
guid 分配勿假设连续（实测序列跳号）。

## 三、AI 写路径配方（核心操作）

```
① 放路点实体（每点一个）
   for i, (x, z) in enumerate(waypoints):
       创建实体(1000000, guid=0x40c00001+i, x=x, z=z)   # 0x40c 段【待复核】

② 创建路径对象（f32 路径库追加）
   path = { guid: 0x40000010, name: '巡逻路径',
            waypoints: [{'entity_index': idx, 'order': i}
                        for i, idx in enumerate(waypoint_indices)] }

③ 巡逻配置引用该路径 guid
   （复杂造物的巡逻组件；若巡逻载体字段未定位，走编辑器原生配置后回读字节）
```

收尾：往返一致性校验；引用序号与实体列表逐一对账。

## 四、与巡逻系统的关系

- 两用途：怪物巡逻（复杂造物 AI）与玩家引导路径
- 巡逻模板三要素：路径引用 + 循环类型（单程/往返/循环）+ 速度参数
- 触发节点：**177（路径到达路点时）**——Trigger 域，逐点触发事件 [C]
