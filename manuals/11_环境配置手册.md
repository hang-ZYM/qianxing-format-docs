# 11 · 环境配置手册

> 任务：配置关卡环境（时间 / 天色 / 氛围）。环境配置存于模板库（.gil 的 f15 区）而非场景数据——可复制、可复用的预设，非每关独有。读法：定位模板 → 读字段表 → 改天色与关键帧。

## 一、结构总览

```
f15[1] 环境配置模板（guid 0x46c00001；0x46c 模板段归属待复核）
 ├─ f4:{f1:1,  f11:{f1:"环境配置"}}      ← 命名组件；组件1→f11 合律 [A]
 └─ f4:{f1:70, f80:{f1:{f1:{            ← 组件70；源卷记 f75，按定律改记 f80（见四）
      f1×N: 1001..1007                  ← 时间预设 ID（7 时段；×8/×7 差一待核）
      f2:1, f6:10, f20:1, f21–f23:1     ← 标志 / 参数 / 开关组
      f8:{3×float32}                    ← 太阳方向向量 (117,138,-180)——向量，非角度
      f9:1, f10:0.3, f14:50, f15:0.003  ← 太阳/月光亮度；亮度范围/速度
      f24:{太阳详细}  f25:{月亮详细}  f29:{月光参数}
      f26:{太阳颜色渐变};  f30–f33:{天空 上/下层×向/背阳};  f34:{地面环境色}
      }}}}}
```

官方功能 ↔ 字节位置 [A]（与官方文档对照）：

| 官方功能 | 字节位置 | 备注 |
|---|---|---|
| 背景预设 | f1×N（预设 1001–1007）| 预设数 7/8 差一待核 |
| 太阳 / 月亮 | f8+f9+f24 / f10+f25 | 方向、亮度、详细配置 |
| 天空 / 环境颜色 | f30–f33（四向）；f30–f34 的 f3 | ARGB 渐变关键帧（见三）|

## 二、颜色编码（ARGB int32）

与实体染色 f3 同编码 [A]：int32，高 8 位 alpha + 低 24 位 RGB；≥2³¹ 须按带符号 10 字节负数 varint 写（同 02 册）。

| 字段 | hex | RGB | 语义 |
|---|---|---|---|
| f26.f2 | 0xFFFFFBE3 | (255,251,227) | 太阳色·暖白 |
| f30.f2 | 0xFF1480BA | (20,128,186) | 天空上层·向阳·蓝 |
| f31.f2 | 0xFF1A3CFF | (26,60,255) | 天空上层·背阳·深蓝 |
| f34.f2 | 0xFF5E1EFF | (94,30,255) | 地面色·紫 |

原卷十进制列换算有误已撤，待回查原始字节 [J，2026-10-04]——四行十进制↔hex 全不吻合（例 4294963395 = 0xFFFFF0C3 ≠ 0xFFFFFBE3）；本表 hex↔RGB 逐行自洽。

## 三、时间渐变系统

```
f3 × N = { f1: ARGB 颜色,  f2: { f1: 通道编号(4–13), f2: 参数 } }
```

- 每组颜色（f26 / f30–f34）内含如上关键帧序列，即"随时间自动切换"的字节基础；官方文档："启用随时间自动切换时，可查看该参数在对应时间点的配置值" [A]；f2.f1（4–13）系渐变通道编号还是时段索引，未定（开放问题）
- 操作含义：改氛围 = 改关键帧颜色；改切换节奏 = 增删关键帧（关键帧级写入未实测，开放问题）

## 四、组件定律适用

定律：配置字段号 = 组件 ID + 10 [A]（组件定律基准）。环境模板组件同守此律；模板库字段号一律先按 ID+10 推定、再对字节复核（docs/18 同批偏差 5 行仅 1 行合律且偏差量互不一致，不可作"定律例外"）：

| 组件 | 配置字段 | 判定 |
|---|---|---|
| 1 命名 | f11 | 源卷自证合律 [A] |
| 70 环境 | **f80** | 源卷记 f75 并称"定律不适用于模板库"——该自我修正已推翻：同文组件1→f11 即合律，f75 系解码误记应重新归因；本册按定律记 f80，待回查原始字节 [J，2026-10-04] |
