# 图模板库

全部模板提取自**编辑器原生创建**的图（金样本纯净性纪律，docs/06 §2），信封结构 f10→f1→f1、容器头部长度字段已修正为真值。可用 `qxfmt inspect <模板>` 查看结构，`qxfmt compose -t <模板>` 做手术合成。

| 模板 | 节点数 | 演示构型 |
|---|---|---|
| `default_graph.gis` | 2 | 最小合法图：事件→打印，自带执行边（docs/22） |
| `dialogue_chain.gis` | 4 | 事件→查询→对话显示链 |
| `branch_loop_vars.gis` | 12 | **构型全家桶**：分支 / 循环 / 图变量读写 / 查询链 / 混合数据流 |

## default_graph（2 节点）

```
实体创建时(71) ──执行边──> 打印字符串(1){文本参数}
```

## dialogue_chain（4 节点）

```
#3 实体创建时(71) ──执行边──> #6 对话显示族(23)
#2 获取场上指定类型实体(319, 悬空查询) ──> #13 对话内容族(130) ──> #6 的数据入参
```

演示：事件起执行链 + 实体查询经中间节点喂参的混合流。注：本图无打印节点，`compose --text` 不适用（换文本用 pbtree 手术）；23/130 为对话域节点（全量词表未收录）。

## branch_loop_vars（12 节点）★构型最全

两条并行主线（`inspect` 实测接线）：

**循环线**（循环 × 图变量 × typed→generic 混合数据流）：

```
#2 获取图变量(339, 悬空查询)
#1 进入碰撞触发器时(92) ──> #3 有限循环(5) ──Iteration──> #4 设置图变量(323) ──> #5 打印(1)
                            │  ↑ 数据入(start/end) ← #2
                            └──End──> #8 设置自定义变量(22) ──> #10 双分支(2) ──True──> #13 打印(1)
                                 ↑ 数据入×2 ← #1, #7(加法运算200)          ↑ cond ← #9(数值大于232)
```

**查询链**（纯数据流四层串联，全部悬空被下游拉取求值——docs/23 §1 惰性求值的实例）：

```
#1(92) → #6 获取自定义变量(50) → #7 加法运算(200) → #9 数值大于(232)
```

构型要点：

- **循环双出口**：Iteration 出口走循环体（写变量→打印），End 出口走后续（设变量→分支）——docs/16 §1 的两种出口各有用途的实例；
- **变量读写闭环**：循环参数由图变量读取（339）喂入，循环当前值每轮写入图变量（323）——黑板变量运行态（docs/23 §5）的完整回路；
- **分支条件来自查询链**：cond 不是字面量而是四层查询的结果——"事件→查→判→做"四段式（docs/16 §4）的典型布线；
- kernel 词表：1=打印字符串 / 2=双分支 / 5=有限循环 / 22=设置自定义变量 / 50=获取自定义变量 / 71=实体创建时 / 92=进入碰撞触发器时 / 200=加法运算 / 232=数值大于 / 319=获取场上指定类型实体 / 323=设置节点图变量；339=图变量读取族（全量词表未收录，337 同族）。

## 用法

```bash
python -m qxfmt inspect templates/branch_loop_vars.gis     # 看结构
python -m qxfmt compose -t templates/branch_loop_vars.gis \
    -o out.gis --text "循环体打印" --guid 0x40000031        # 手术合成（有打印节点）
python -m qxfmt verify out.gis                              # 规则校验
```

扩展新模板的路径：从**编辑器原生创建**的存档分片里提取图载荷 → 按本库脚本的信封包装 → 严格容器断言过 → 入库（禁止用第三方生成的内容归纳构型）。
