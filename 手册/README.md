# docs/ — AI 参考层（机器导向）

> **本层是写给 AI 的机器导向参考**：密集表格、字段号、术语压缩、证据分级标记——这是为 AI 检索与执行优化的设计形态，不是排版缺陷。
> **人类读者请从仓库根 [README](../README.md) 与 [guide/](../guide/)（人读层，v2.0 新增）开始**；任务导向的操作手册在 [manuals/](../manuals/)（按任务查册）。

## 证据与仲裁纪律

- 证据分级：[A]字节实证 / [J]可复现判例 / [P]schema 注释推断 / [K]知识库存档 / [C]目录数据 / [D]官方文档 / [?]未定案
- 仲裁规则：**字节 > 卡片 > 枚举名**（原表见入口卷 [30 §5](30_任务分解与模块化方法论.md)）
- 修正带依据、翻案留痕——勘误沿革以卷内注记为准，旧说加删除线保留
