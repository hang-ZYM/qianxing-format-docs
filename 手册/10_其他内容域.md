**f11.f1 的时间子字段（关卡时间）**

关卡运行时的「初始时间 + 流逝速度」不住在环境载荷（`f75`）里，而在**关卡设置 `f11.f1`** 内：

| 字段 | 语义 | 类型 | 默认 | 值域 | 证据 |
|---|---|---|---|---|---|
| `f11.f1.f17` | 关卡初始时间点（小时） | int | **10** | 0–24 | [A][D][R] |
| `f11.f1.f18` | 每秒流逝时间（分钟）= 流逝比例 | float | **24** | 0.01–60（**缺失=0**） | [A][D][UI][R] |
| `f11.f1.f1` | 生效范围（vec3） | vec3 | — | — | 推断（字段归属）+ 人工核验（规则） |

- 界面「每秒流逝时间（分钟）」与 `f11.f1.f18` **数字一一对应、无需换算**（[J]）。
- **无环境级「流速」字段**：推进速度只由关卡级 `f11.f1.f18` 或节点（kernel **665 设置当前环境时间** / **666 设置环境时间流逝速度**）决定；「时间」环境**不自带流速**（[A]）。
- **「时间」环境** = `f15` 的**第二条 `tc=26`** 条目，guid 落 **`0x46C` 段**（出厂槽 `0x46C00001` 之外的第二条，`0x46C00002`）——一个**自带时点表**的「随时间自动切换」环境（cfg 顶层 `f3=1` + 每组内 `f1=1` + 组内 `f3` 时点表，即"时间推进三件套"）。它与 `f11.f1.f17` / `f18` 是**配套关系**（f11 定起点与流速、环境定"各时点长什么样"），**非替代**（[A][D]）。
- 上表证据标注沿用全局体例：**[A]** 字节实证 / **[J]** 判例·实测 / **[D]** 官方文档 / **[UI]** 编辑器界面 / **[R]** 反编译（只留字段号与类型） / **[H]** 推断 / **[?]** 未定。字段字典与「666 提瓦特速度三源冲突」等未定项见 **20 篇 §8**；概念映射见 docs/04 §2.B。

## 2. 独立文件族

### 2.1 local_setting.gils（地图本地设置）[J]
容器类型码 **8**（806 魔数族）。实测结构：

```
{ f1: 地图id
  f2/f3/f4: 设置串（如 "PropertyTransform" 属性变换配置）
  f5: 协作分区配置（联机关卡含 "协作部分_1..N" 分区名表）
  f6: 时间戳
  f7: 属主玩家 uid   ← ⚠ 含个人标识，分享/开源前必须脱敏
  f8: 地图id }
```

### 2.2 external_lua_file/（客户端 Lua）[K]
地图目录下的客户端脚本目录。Lua 与服务器节点图构成**双语分工**：服务器图管逻辑判定，客户端 Lua 管表现/界面。平台提供受限 Lua API（沙箱禁令多）。图↔Lua 通过信号系统（SignalSignature{signal_name, server_node_id, client_node_id}）互通。

### 2.3 .gilh（地图实体索引）[J]
容器806族。含地图名 + 实体摘要表（guid/分组/名称），编辑器地图列表与实体枚举的缓存。

### 2.4 .gir（运行时数据）[K]
已发布关卡的服务器运行时数据（Beyond_Local_Save_Runtime，按发布 id 存放）。

### 2.5 RuntimeCustomAssetPack [K]
自定义资源包目录（商城/导入资产的本地缓存）。

## 3. 各域已知语法摘录

- **地形（f7）**[K]：20×20 格网制；每格高度/材质待字段级逆向。
- **实体分组树（f6）**[A]：树形注册表；怪物实体必须在 f5（实体列表）与 f6（分组）双注册，只注册一边不生效。
- **UI 布局库（f9）**[K]：控件树序列化；树内节点类型含容器/图片/文本/按钮族；图库注册机制（树 204 节点）已定位，全 schema 待逆向。容器结构有编辑器二进制逆向佐证（`RepeatedField<int>` 注册表 + `RepeatedField<控件实例>`，见 §1 f9 行与 §4.5）。平台禁自定义图片上传（imageId 只读，仅官方图库+真实 NPC 模型可用）。
- **资产库（f15/f16）**[A]：战斗预设自定义资产主库 + 去名副本库；类型码实测表/出厂五条目/双写白名单见 18 篇。技能 guid：怪物/造物技能 0x470 段、角色自定义技能 0x418 段、官方技能样库 0x474 段（18 篇 §5）。
- **属性注册表（f22）**[K]：28 类属性模型（含敌意 PropertyEnmity、颜色材质 PropertyModelColorMaterial 等）；怪物配怪必注册敌意属性。
- **路径库（f32）**[A]：路径对象走 0x400 段 guid + f6 树形组织（树 36/叶 4900）；路点=**内联世界坐标 float3**（路点实体只是 (0,2000,0) 天上锚点壳，不带位置）；巡逻参数不在 f32，在造物 comp65（载荷 f70）——全链 schema 见 19 篇。
- **装饰物**[K]：DecorationItem={name, template_id, pos, scale, yaw_deg}，走 gia 通道，实体侧以 type14 子物体 + 40 引用挂载。
- **特效**[K]：f7 槽组件 → {挂点: GI_RootNode, 模板 id}；特效库 498 个 id 已众包枚举。

### 4.4 元件双号制 [A]

元件系统是"模板层 ↔ 场景层"两套号并行的典型：

- **元件 id ∈ 0x40C 段**：`0x40C00001` = 「默认模板」根（每图内置，asset_id 恒 = 1000000）；用户元件自 `0x40C00002` 起；
- **实例化后的主件实体 guid ∈ 0x404 段**（机关段）——"创建元件"节点引用的是 0x40C 模板 id，落到场景里的是 0x404 实体。

自造 guid 前必须全档扫描避撞（跨段复用会引发引用歧义；0x478 段有官方自动物化条目，同样在扫描范围内）。

## 4.5 首攻成果（2026-09-29 挖掘第一轮）

- **A2 属性注册表 ✅schema**：见上表 f22 行。位图与类名一一对应，可按需启用。**编辑器自动维护**——编辑器里使用某功能（染色/隐藏等）时对应属性类自动追加注册（实测 2 类→14 类）。
- **A1 UI 布局库 ✅三轮(2026-09-29深夜)**：
  - **f501 = 模板guid注册表**（135B 裸 varint 序列，27 个 guid，不是 protobuf）
  - **模板定义不在 .gil 里**：29 个模板 guid 全部只出现在 f9 内部（追踪验证 0x40000045/0x40000 036/0x40000121 等均零外部命中），且仅 2/27 与 f10 图库重叠（还是系统根 guid）
  - **结论：控件模板是编辑器内置类型系统**（同实体 prefab 的关系——.gil 只存"哪个类型放在哪+覆盖值"，类型定义在引擎侧）
    > **⚠ 2026-10 更新注记**：上两行的"29 内置"结论**已被全档对拍动摇**——另一官方剧情展示图实测 f501 注册 575、f502 控件 4130 件（2.8MB）、**f504 模板 guid 达 536 种**（0x4000 段动态分配）。"模板=固定内置类型"的推断不再成立，模板面是**动态分配的资产面**，模板定义存放地回到待核。当前可依赖的定案只有：容器结构（f501 注册表 + f502 实例，有编辑器二进制逆向佐证）、声明式绑定语法、单图内的 guid 追踪事实。
  - 实例 schema（前轮）：f502×N = {f501 实例guid, f502×N 子组件, f504 模板guid, f505×N 内容块}
  - 内容块/绑定（前轮）：{f11-f28 属性槽, f501+f502 (键,值), f503 嵌套绑定记录×446 含 `{1:ps.变量}` 表达式}`f502×N = {f501:实例guid, f502×N:子组件引用(395), f504:模板guid(29种), f505×N:内容/覆写块(677, 占87%字节)}`；实例层 `f503×29 = guid区间对(分配窗口)`；内容块与子组件共用 schema `{f11-f28:属性槽, f501+f502:(键,值)varint对, f503:嵌套绑定记录}`；**嵌套绑定记录×446 = {guid三元组, f504:绑定表达式}**——`{1:ps.变量.N}` 表达式原文在此。0x40000001=系统根id(各子系统首对象通用)。**模板定义的存放地未定位**（非 f8 布设组、非实例层 f503）= 第三轮目标。
- 音频域定位线索：PropertySoundEffect 属性类（f22 注册后实体侧挂音频属性）。
