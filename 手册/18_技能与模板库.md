# 18 · 技能与模板库（f15/f16 资产库域）

> 本卷覆盖战斗预设的自定义资产域：**f15 = 自定义资产主库**、**f16 = 去名副本库**。
> 2026-10 全图集实测刷新：f15/f16 的定性从早期"默认模板库/自定义模板增量"升级为
> 覆盖 20+ 类型的资产库，类型码/段位/双写白名单均已定案（旧定性作废，见各节注记）。
> 证据分级同前：[A]字节实测 / [J]判例 / [K]知识库存档 / [?]未逆向。

## 1. f15 = 自定义资产主库

战斗预设页签（技能/职业/道具/单位状态/环境配置……）里用户新建的每一样资产，都落在这里。
f15 在所有地图（含空白图）都在位——空白图里是编辑器的**出厂默认资产集**（五类，§1.2）。

### 1.1 条目结构 [A]

每条目 = `{ f1: guid, f2: 类型码, f4×N: 配置段, f5: 尾部 }`（编辑器二进制逆向的字段清单与字节吻合）：

- **f1**：资产 guid，段位由类型决定（§1.3 段位列）
- **f2**：类型码——f15 内部的类型编号体系，**与编辑器资产类型枚举（09 卷）是两套编号，勿混**
- **f4×N**：配置段，每段 = `{ f1: 段号, f(载荷字段号): 载荷 }`；段 1 恒为名字段（载荷 f11）
- **f5**：尾部（实测内容极少）

### 1.2 出厂默认条目（五类，每图在位）

## 2. f16 = 去名副本库（双写镜像）

f16 在空白图为空；用户添加过资产后出现。条目 = `{ f1: guid, f2: 同 guid, f3×N: 配置块 }`——
与 f15 的两处结构差异：**无类型码**（f2 是 f1 的副本）、配置块挂在 f3。因副本不带名字串，故称"去名副本"。

**双写白名单 [A]**——只有这些段位的资产会同时写进 f15 与 f16：

```
{ 0x404 单位状态族, 0x418 自定义技能, 0x420 道具+装备, 0x470 怪物技能, 0x478 特效器, 0x494 载具操控技能 }
```

- 经济管理面资产（货币/背包/装备栏/商店等）**不入** f16
- 护盾（0x450）/ 扫描标签（0x454）实测**不双写**（白名单外反例在档）
- 成长曲线/技能资源/技能属性组等**单容器资产**不双写（一般也不进资源树）
- 双写的触发时机未定位 [?]

双写族的资产以 **f15 + f16 + f6 资源树三处一致**登记（三容器联动）；单容器资产只有 f15 在位。
解析/校验时按此分层，对单容器资产查树注册会误报。

### 2.1 示例：道具条目的镜像（模板图实测 91B）

```
f16.f1 = {
  f1: 0x42000001 (guid)
  f2: 0x42000001 (同 guid)
  f3: { f1:39, f49: { f1: {f1:9999, f3:1, f4:4202, f5:4301, f6:引用5B, f502:1} } }
}
```

## 3. 配置段编码：段号 ≠ 载荷字段号（每类型实测）

配置段 = `{ f1: 段号, f(载荷字段号): 载荷 }`。早期"载荷字段 = 段号+10"的猜想**不成立**——
段号与载荷字段号是两套独立编号，+10 只是高频巧合：

| 实测例 | 映射 | 偏移 |
|---|---|---|
| 道具 段 39 → f49 | 命中 | +10 |
| 技能 段 21 → f30 | 偏离 | +9 |
| 技能 段 35 → f45 | 命中 | +10 |
| 背包模板 段 42 → f55 | 偏离 | +13 |
| 单位状态 段 2 → f21 | 偏离 | +19 |
| 护盾 段 51 → f61 | 命中 | +10 |
| 扫描标签 段 55 → f67 | 偏离 | +12 |

结论：**每个类型的段位-字段映射按该类型 schema 实测**，不可跨类型类推。

## 4. 技能资产的形态

技能是 f15 的**独立条目**（早期"技能藏在职业模板深层"的读法已废）：

- 角色自定义技能（类型码 6，0x418 段）/ 怪物造物技能（类型码 28，0x470 段）共享同构时间轴体：
  - **段 21 数值配置**：冷却时间/索敌半径/消耗类型（引用 0x41C 技能资源）/技能属性组（引用 0x47C）
  - **段 35 动画轨道体**：轨道四类（开始事件/结束事件/节点图事件/状态轨道）+ 动画槽位
    （引用 0x408 段客户端图 + 0x1000 段动画 id）
- 职业（类型码 4）经**技能槽位配置**引用技能；技能编辑入口在战斗预设页签
- 配套资产：技能资源（类型码 7，0x41C——气/通用技能点/魔力等消耗池）、技能属性组（类型码 31，0x47C——动画速度/冷却倍率）

**官方限额**：自定义技能 ≤1000、造物技能 ≤50、职业可配置技能 ≤50、技能资源 ≤2000、技能动画 ≤100。

## 5. 0x474 段 = 官方技能样库（与 0x470 双轨）

怪物 AI 组件引用的技能有两个来源、两个 guid 段 [A]：

| 段 | 归属 | 内容 |
|---|---|---|
| **0x470** | 用户侧 | 战斗预设里自建的怪物/造物技能（f15 类型码 28 条目） |
| **0x474** | 官方侧 | **官方技能样库**：全图集仅 13 个 id（0x47400001-0d）跨图共用；f15/f16 无条目、资源树无注册——不落存档的官方内置库 |

引用形态：怪物实体的怪物 AI 组件载荷 `{ f1: {f1:1, f2:0x474xxxxx}, f2:1 }`（与技能背包条目同构）。
官方怪走 0x474 引用、自定义怪走 0x470，双轨并存；0x474 无创建/编辑入口（引用面只读）。

## 6. 与其他系统的关系

| 系统 | 位置 | 关系 |
|---|---|---|
| 自定义职业 | f15 类型码 4（0x410 段） | 经技能槽位配置引用技能；guid 0x410 段与模板层角色对象同段异层（见 10 卷段位表） |
| 技能 | f15 类型码 6/28 | 被实体技能背包组件引用（0x470）；段 35 时间轴引用客户端图 |
| 成长曲线 | f15 类型码 5（0x414 段） | 等级倍率表 ×200；被职业引用；0x414 段实体层=关卡实体，同号不同物 |
| 背包模板 | f15 类型码 12（0x42C 段） | 被实体背包组件引用 |
| 环境配置 | f15 类型码 26（0x46C 段） | 表现层预设，见 20 卷 |
| 道具/装备 | f15 类型码 9/10（0x420 段共段） | 商店/掉落/背包系统的物品定义 |
| 特效器 | f15 类型码 32（0x478 段） | 被图节点按配置 ID 引用（与官方小整数特效 id 混用同一引脚） |
| 编辑器资产类型枚举 | 09 卷 | 与本表类型码是**两套编号**，对照时务必注明体系 |
