# 31 · 单位状态与可见性（f15 tc=1 状态 / 组件 f7#14 / 状态节点图 / 效果池 / 模型静态可见性）

> 概念到字节的**映射表**见 `docs/04_对齐.md` §2.D；两处结论一致，冲突时以字节与 `docs/04` 为准。

## 1. 一条单位状态落在哪（三处注册）

一条单位状态 = `f15` 里一条 `tc=1` 条目，guid 落 **`0x404` 段低位**（与机关实体共段，资产占低位；段位表见 10 篇 §4.2，类型码表见 18 篇 §1.3）。

| 落点 | 形态 | 说明 | 证据 |
|---|---|---|---|
| `f15`（**定义**） | 一条 `tc=1`，guid `0x404` 段低位 | 命名段 + 数据段（§2） | [A][D] |
| `f16`（**副本**） | 一条 `{f1:guid, f2:同 guid, f3×2:配置块}` | 「去名副本」；`0x404` 单位状态族在 f16 双写白名单内（18 篇 §2） | [A] |
| `f6`（**资源树注册**） | 类别 **11**（RoleStatus）下一条叶 `{f1:**1900**, f2:<状态 guid>}` | `1900` = `CUSTOM_ROLE_STATUS`（18 篇 §1.3 类型码 1 行）；与 20 篇 §12「环境注册 category」同一层 | [A] |

- **三容器联动**：双写族的资产以 `f15` + `f16` + `f6` 资源树**三处一致**登记（见 18 篇 §2）。
- 状态 **不在 `f10`**：状态与状态节点图的关联**不经 `f10`**（[A]；图的 guid 只在状态主体里，见 §4）。
- **「空态也带 `f6=30001`」的确切所指**：这是**状态主体内部**的一个定值字段（§3），与上面「资源树容器 `f6`」**同号异物**——两处不可混读（[A]；措辞澄清见 §12）。

## 2. `f15` 条目结构（定义）

```
f15 条目（一条单位状态）
 ├ f1  uint      状态 guid（0x404 段低位；写前须全档扫描防撞号）
 ├ f2  uint      类型码 = 1（单位状态）
 └ f4  repeated  两段
    ├ 段A = { f1:1, f11 { f1: <状态名, UTF-8> } }      命名段
    └ 段B = { f1:6, f21 { f1: <状态主体> } }            数据段
```

- 状态**全局唯一命名**（编辑器「新建状态」时生成配置 ID；重名由界面拦）[D][UI]。
- `f4` 的**两段**在样本里恒为「段A 命名 / 段B 数据」的定序；段 B 是效果与规则的唯一载体（[A]）。
- 「复制状态」按钮会带出一份同构条目、**换新 guid**（[UI]，形态未逐一实证）。

## 3. 状态主体 schema（段 B 的 `f21.f1`）

```
状态主体
 ├ f1  基础规则组   { f1:f32, f2:{节点图绑定}, [f4:1], f5:1, [f6:1], f9:f32 }
 ├ f2  并存 / 叠层组 { f1:1, f3:1, f4:1 }        （部分样本缺 f1）
 ├ f3  效果引用组    { repeated f1:效果组, [f2:<裸字节尾>] }
 ├ f4  让位列表      {}                          （观测为空）
 ├ f5  顶替列表      {}                          （观测为空）
 └ f6  = 30001                                  （定值）
```

| 字段 | 类型 | 语义 | 证据 |
|---|---|---|---|
| `f1.f1` | f32 | 未定（样本值 1.0 / 5.0，**疑初始运行时长**） | [A] / [H] 语义 |
| **`f1.f2`** | msg | **节点图绑定**（§4） | [A] |
| `f1.f4` / `f1.f5` / `f1.f6` | uint | 标记位（`=1`；`f4` 在部分样本缺席） | [A] |
| `f1.f9` | f32 | 未定 | [A] |
| `f2` | msg | 并存 / 叠层规则组 | [A] / [H] 逐位 |
| **`f3`** | msg | **效果引用组**（§8 的效果池 id 落在这里） | [A] |
| `f3.f1` | repeated msg | 效果组：`{f1:<效果模板 id>, f2:参数条目×N}` | [A] |
| `f3.f2` | bytes | **裸字节尾**（空壳态与有态**都带**）；疑 packed varint 列表，**语义未解** | [A] 形态 / [?] 语义 |
| `f6` | uint | **`=30001` 定值**（空壳态也带；**与效果无关**，疑图标 / 分类 id） | [A] / [H] 语义 |

- **空壳状态** = `f3` 里**只有 `f2` 尾、没有 `f1` 效果组**——官方允许「只绑图、不带效果」的状态（[A]）。
- 让位列表 `f4` / 顶替列表 `f5` 观测为空；官方有「状态并存 / 让位 / 顶替」六组配置界面（[D]），逐项对号**未做**（§11）。
- 效果**参数条目** = `{f1:子参数 id, f10 / f12 / f13:TypedValue 槽, f3 / f5 / f6:值}`；逐位语义**未全破**（[H]）。

## 4. 「绑定节点图」（状态 → 状态节点图）

落点 = **状态主体的 `f1.f2`**（§3），两种形态：

```
无图 = { f501:20003 }                              （只带类别标记）
有图 = { f1:1, f2:<状态节点图 guid>, f501:20003 }
```

- `f501:20003` = **状态节点图类别**（与 §6 图头类别码同表；与图头 `f2=20003` 呼应）[A]。
- 图 guid 落 **`0x4000` 图域**（多命名空间池，同号跨域合法；见 10 篇 §4.2），且该 guid 同时出现在 `f6`（资源树）与 `f10`（图区）——但**状态与图的关联本身不经 `f10`**（[A]）。
- **一个状态最多绑 1 张状态节点图**（[D] 明文）。
- **出件纪律：`f15` 段 B 与 `f16` 副本两处都写。** 实测样本出现过**两边不一致**（一侧带图、另一侧缺席）⇒ 只写一侧会踩坑；**哪一侧是权威 = 未判**（[A] / [?]）。

## 5. 单位状态组件（把状态挂到实体上）

```
实体 f7 槽 · 条目 = { f1:14, f2:1, f24:<载荷> }
载荷 f24 = { repeated f1: 配置项 }
配置项   = { f1:{ f1:1, f2:<状态 guid> }, f2:<初始层数> }
未配置   = f24 零长
```

- 定案三件套 = **`(槽 f7, cid 14, 载荷字段 f24)`**；载荷字段号 = `cid + 10`（组件律见 12 篇 §0）。
- **空存根默认在位**：多数实体出厂自带一个 `f24` 零长的 `(f7,14)` 条目（**默认挂载组件**，空态就在位）。
- **同号异槽警告**：`(f5, cid14, 载荷 f23)` = **动作组 MPActionGroup**，与 `(f7, cid14, 载荷 f24)` = 单位状态组件是**两回事**——记组件必须记 **(槽, cid, 载荷字段) 三件套**。
- 官方（[D] 强）：「单位状态组件是**所有单位的默认挂载组件**」——实体 / 元件都能在组件页签直接找到，**不需要为了挂状态而引入怪物实体**。
- 组件侧操作（[D][UI]）：组件页签 → 选状态 → 配**初始层数**；实体创建时由关卡实体施加，施加顺序 = 组件内配置的**从上至下**；同一状态在一个组件里**只能被施加一次**；一个组件可同时配多个状态。
- **生效目标限定**（[D] 强）：每个**效果**只允许对「**角色 / 造物 / 物件**」中的一种或几种生效；**「若该状态中存在某个效果无法对该实体类型生效，则目标实体会无法成功持有该状态」**。

## 6. 状态节点图与图头类别码

### 6.1 图头与节点身份

```
图头     = { f1:10000, f2:<图类别>, f3:21001, f5:<图 guid> }
节点身份 = { f1:10001, f2:20000(恒), f3:22000, f5:<kernel id> }
```

- **类别码在「图头 `f2`」**；节点身份里的 `f2` **恒 = 20000**（即便在状态图里）——只有图头是类别（[A]）。
- 类别码表（[A]，多图对拍）：

| 图头 `f2` | 类别 |
|---|---|
| `20000` | 服务器节点图 |
| `20001` | 过滤器节点图 |
| `20002` | 技能节点图 |
| **`20003`** | **状态节点图** |
| `20004` | 职业节点图 |

> 节点与图的**全表**见 07 篇；类别码在 03 篇 §2.0 亦有。本卷只收与本域相关的这一张。

### 6.2 状态图入口节点

- 状态图入口 = **kernel `300`「单位状态变更时」** / **kernel `299`「单位状态结束时」**（[A] 真图实证）。
- **状态图没有专门的「状态开始」节点**——入口就是 `300` / `299`（图随状态挂到实体，故它们在该实体上触发）[A]。
- `300` 官方功能描述：单位状态**层数发生变化**时触发，**施加与移除都会触发**（07 篇 §300，[D]）。
- **待核**：「进状态是否触发 `300`」「`299` 在状态结束（图被移除）的时序里能否执行」= **推断，未测**（[H]，§11）。

### 6.3 图在 `f10` 的嵌套与写图

- `f10.f1.f1 = { f1:图头, f2:图名, f3:节点×N }`；**空图无 `f3`**（[A]）。
- 造状态图时**必须显式给 locator 类别 `20003`**（图装配工具的默认类别不是状态类）——这是出件时唯一需要外传的参数（[A]，工具行为见 `docs/04` §2.D 原语列）。

## 8. 效果池 id（状态「效果」的模板编号）

| 模板 id | 效果 | 依据 | 证据 |
|---|---|---|---|
| **`770001`** | **角色隐藏**（隐身） | 多个来源的状态（隐身 / 隐藏角色 / 角色透明 / 玩家隐身 / Invisible）**无一例外**用同一 id | **[A] 强（多源）** |
| `680001` | **铭牌隐藏** | 多源（隐藏铭牌 / 怪物隐藏铭牌） | [A] |
| `780001` | **隐藏实体的小地图标识** | 多源（圆环隐藏 / 护卫-隐藏 / 不可见） | [A] |
| 其余全表（无敌 / 锁血 / 禁止移动 / 护盾 / 挂载特效…） | 见官方效果池 | **批量反推**；除少数多源项外**单条未逐一实证** | [H] |

- `770001`（角色隐藏）的参数形态 = **布尔型本地过滤器 + 「屏蔽特效」「屏蔽音频」两开关**（[D]）；官方原文：「**半透明、全透明，都是隐藏的一种状态**」——判定 true → 虚化半透明；false → 完全隐藏（[D]）。
- **`770001` 只对「角色」生效**。挂到非角色实体（造物 / 物件）**很可能静默不生效**（不是崩，是「没挂上」——由 §5 生效目标限定推得）——**未实测**（[H]）。
- **`物件不可见` / `造物不可见` 的效果模板 id = 抽不到**：官方面板项确有（[D]），但**全档普查里零个状态使用它们**，无法从字节反推。曾出现过单个候选 id（记为 [?]，来源命中太少、**不作数**）。这是「造物 / 物件隐身」走效果池**唯一缺的一块料**——补法只有一张编辑器原生样本（§10）。

## 9. 模型的静态可见性（另一条独立路径）

```
实体 f6 槽 · 条目 = { f1:8, f2:1, f18:<载荷> }
载荷 f18 = { f1:1, f501:1 }   → 可见
载荷 f18 = { f501:1 }         → 不可见（★「删 f1」）
```

- 组件定案 = **`(槽 f6, cid 8, 载荷字段 f18)`**（`PropertyStaticVisible`）；`f18` **删 `f1`** ⇒ 不可见（[A] 形态）。
- 这是 **prefab 出厂自带的标准组件**，多数实体在位（见 11 篇 §4 / 12 篇 §2）。
- **它与单位状态路是两条不同机制**（§10）：
  - `f6#8` 只有**「模型可见 / 不可见」一个布尔**；
  - 单位状态还带**状态存在性**（可被节点查询 / 移除）、半透明档、屏蔽特效 / 音频、以及叠层 / 时长 / 让位 / 顶替的整套规则。
- **互为替代**：若节点 `308` 对造物 / 物件不生效，**唯一近亲替代是 `f6#8`（静态可见性），不是另一个节点**（[H]）。
- **证据分级**：形态 = [A]；「删 `f1` = 不可见」= **编辑器内 diff 判例 [J]**；**运行时 / 试玩是否同样生效 = 未验**（[H]，§11）。

## 10. 出件与读写（可复制规格）

> 目标：造一个状态 + 挂到目标实体 + （可选）绑一张状态节点图。字段路径 → 值 → 类型 → 证据。

**① 状态定义（写进 `f15`；同步镜像一份到 `f16`）**

| 字段路径 | 值 | 类型 | 证据 |
|---|---|---|---|
| `条目.f1` | 新 guid（`0x404` 段低位，**写前全档扫描防撞号**） | uint | [A] |
| `条目.f2` | `1` | uint | [A] |
| 段A `.f1` / `.f11.f1` | `1` / `"<状态名>"` | uint / string | [A] |
| 段B `.f1` / `.f21.f1` | `6` / `<状态主体>` | uint / msg | [A] |
| `主体.f1.f1` / `.f1.f9` | `1.0` | f32 | [A] |
| `主体.f1.f2` | 无图 `{f501:20003}` / 有图 `{f1:1, f2:<图 guid>, f501:20003}` | msg | [A] |
| `主体.f1.f5` / `.f6`（有 `f4` 时也写 `.f4`） | `1` | uint | [A] |
| `主体.f2` | `{f1:1, f3:1, f4:1}` | msg | [A] |
| `主体.f3.f1` | 效果组（角色隐藏 = `f1:770001`；空壳省略；**物件 / 造物未知**） | repeated | [A] / 抽不到 |
| `主体.f3.f2` | 裸字节尾（**照抄同类样本**） | bytes | [A] 形态 / [?] 语义 |
| `主体.f6` | `30001` | uint | [A] |

**② 资源树注册（写进 `f6`）**：类别 `11`（RoleStatus）下一条叶 `{f1:1900, f2:<状态 guid>}`（[A]）。

**③ 挂到实体（写进该实体 `f7` 槽）**：条目 `{f1:14, f2:1, f24:{f1:{f1:{f1:1, f2:<状态 guid>}, f2:<初始层数>}}}`；空态 = `f24` 零长（[A]）。

**④ 绑状态节点图**：图头 `{f1:10000, f2:20003, f3:21001, f5:<图 guid>}`；状态主体 `f1.f2` 写带图形态，**`f15` 与 `f16` 两处都写**（[A]）。

- **读写边界**：本域的**读**已验（字节形态、三处注册、组件、图绑定）；**写回未验**——把状态条目写进一张新图后**编辑器是否接受、组件是否生效、图是否被规范化重排 = 未测**（[H]，§11）。
- 只读阶段已见：条目可整块对拍、可整块搬运；**本卷不载任何具体存档的逐字节载荷**。
