# 14 · 节点连线兼容（类型匹配律）

> **规则**：执行线 Flow→Flow 任意节点可连；**数据线要求两侧类型相等**（泛型节点按实例化后的具体类型算）。
> 语料验证：4615 条真实连线中执行线 1629 条、数据线 2986 条类型相等——**错配 0 条**。

> 含义：兼容性是**类型级**的而非节点级——"Bol 出 → Bol 入"永远可连，与是哪个节点无关。

## 1. 例：你画布上看到的行为，规则怎么解释

| 连线 | 结果 | 规则 |
|---|---|---|
| 是否相等 → 双分支 | ✅ 可连 | 是否相等出参 `ok:Bol` ＝ 双分支入参 `condition:Bol` |
| 取自定义变量 → 双分支(条件) | ❌ 不可连 | 取变量出参是 `R<T>` 泛型，未实例化不等于 `Bol` |
| 取自定义变量(布尔变量) → 双分支 | ✅ 可连 | 实例化 T=Bol 后出参变 `Bol`，同型可连 |
| 数值大于 → 双分支 | ✅ 可连 | 出参 `Bol`（比较结果天然是布尔） |
| 碰撞触发 → 取自定义变量(目标实体) | ✅ 可连 | `enteringEntity:Entity` ＝ 取变量入参 `targetEntity:Entity` |
