# 19 · 路径系统（f32）

> 官方文档 × 字节解码。2026-10-13 字段级定案：309 件 .gil 全量普查（265 件空体 / 42 件非空全查）
> + 多图深解剖（1975 / 樱花观景 / 洛斯里克高墙 / 2D塔防 / 3D塔防 / 夏日冲浪 / AK射击 / 键盘钢琴 / 你画我猜）。
> 证据分级同前：[A]字节实证 / [J]判例 / [K]知识库存档 / [?]未定案。

## 1. 官方语义

路径 = 一组有序的**路点**。官方文档明示："路径中的路点信息为**世界坐标和旋转**，不会因为被引用而被调整数据内容"——路点是自持几何，不是对场景实体的位置引用（§5 翻案）。用途：
- **造物巡逻**（未入战-巡逻功能）
- **基础运动器的关卡路径运动**（沿路径移动的平台/机关）

巡逻循环类型：单程 / 往返 / 循环。

## 3. 路径对象 schema（字段级）[A]

```
f32 ─ f1（重复＝路径对象）
  ├─ f1 = guid（varint，0x400 段）
  ├─ f4（组件槽·命名）= { f1: 1, f11: { f1: 名称字符串 } }          ← 组件1→f11
  ├─ f4（组件槽·路径数据）= { f1: 54, f64: <路径数据> }             ← 组件54→f64
  └─ f5（组件槽·变换）= { f1: 1, f11: { f1: 位置float3, f2: '',
                                         f3: {1.0,1.0,1.0}, f501: 0xFFFFFFFF } }
```

**路径数据（comp54→f64）**：

```
f64 ─ f1（路径数据节点，单条）
  ├─ f1 = 路径 guid（自指，与外层一致）
  ├─ f3（重复）= 路点（schema 见 §4）
  ├─ f501 = 1（多数）或缺席——路径级版本式标记，非序号
  └─ f502 = 1（仅塔防双图 6 条路径出现）——语义未定 [?]（疑锁定变换/场景显示开关）
```

**空路径最小形态**（74B，洛斯里克高墙 0x4000000b 实测）：

```
{ f1: guid, f4{f1:1, f11{f1:'路径_3'}}, f4{f1:54, f64{f1:{f1:guid, f501:1}}}, f5{变换槽} }
```

- **路径名称**：官方要求"名称不可重复"，但商城图实测名称全空串——命名非必需。
- **变换槽（f5）**：145/145 全零位置——官方"路径中心点位置/旋转"**未持久化于此** [?]。

## 4. 路点 schema（逐字段）[A]

路点 = 路径数据节点下的**重复 f3**。全语料 685 路点采样，字段签名仅 {1,2,3} / {1,2,3,501} 两种 + 罕见变体：

| 字段 | 类型 | 语义 | 值域/证据 |
|---|---|---|---|
| f1 | varint | **实体表 0 基索引**（f5 实体列表下标） | 1975 铁证：wp f1=2→entity[2]=0x41000001、4→entity[4]=0x40c00003（路点标记）。**可指任意实体**：樱花观景 140 路点中 44 指路点标记(aid 1000000)、96 指造物/物件(200010xx)、4 指出生点。段位定性见 10 篇 §4.1 |
| f2 | float3 | **世界坐标（几何真源）** | body 15B=3 浮点(679×)、10B=2 浮点(6×)、5B=1 浮点(1×)——proto3 零值省略；值域连续（洛斯里克 y=131.58 高空、2D塔防 y=-0.85） |
| f3 | float3 | **旋转（真源）**，零值省略 | f2=偏航为主域（2D塔防 ±90）；1975 全路点=(30.73,180,180)；三轴约定与实体一致 f1=X f2=Y f3=Z |
| f501 | varint | 0 基顺序号，**首点缺省(=0)** | f501 vs 数组序 **228/228 零失配**（四图）；1975 测试路径 [缺,1,2,3,4,5,6] |

## 5. 路点几何真源 = 内联坐标（2026-10-13 翻案）

**旧说（已废）**："路点=引用实体，实际位置存在路点标记实体的位置组件里，移动标记即更新路径"。

**新定案 [A]**：

1. **几何真源在路径内联（f2/f3），不在实体**。路点实体（aid=1000000）全部停在 **(0, 2000, 0) 天上锚点**（1975 10/10、樱花观景 10/10）——它只是锚点壳，不带路点位置。内联坐标 vs 实体 transform 镜像匹配 **0/228**（零命中=实体位置组件里根本没有路点坐标）。
2. **标记实体是共享池**：樱花观景仅 10 个标记实体被 44 个路点引用（8 个被多点共享）；1975 9 个标记对 23 路点。
3. **路点可锚定任意实体**：出生点、造物/物件皆可作 f1 索引目标；f1 疑为编辑器侧簿记（运行时是否读取未定 [?]）。

设计理解修正：官方"不会因为被引用而被调整数据内容"即内联几何的表述——**移动路点标记实体不会更新路径**（旧说的"引用跟随"设计意图不成立）；编辑器里拖动路点改的是 f32 内联坐标。AI 写路径时 1:1 放标记是官方行为（共享池）的超集，安全。

## 8. 巡逻参数不在 f32——在造物 comp65 [A]

**关键翻案**：逐路点巡逻参数**不在路径域**，住在造物/怪物实体的**组件 65**（怪物 aid=3000xxxx，槽 {f1:65, f70:载荷}；载荷字段=cid+5——+10 律的例外实证）：

```
实体.f5槽 { f1: 65, f70: <载荷> }
f70 = { f1: '' （无巡逻） | { f2: <巡逻模板>（重复） } }
巡逻模板 = { f1: 1?, f2: '模板_1', f3: <模板参数>, f4: <路径引用> }
模板参数 f3 = { f1?: 1, f2: 循环枚举 3800/3801/3802, f3?: 1(仅3802时见), f4: 1 }
路径引用 f4 = { f1: 路径guid, f2:（重复）逐路点参数行 }
参数行 f2 = { f1: 路点实体序号, f2: 速度枚举, f3: 3700, f4?: 半径float, f5?: 1, f6?: {f1: 停留秒} }
```

## 9. 读写律（f32 字节可写——实验证明 [A]）

1975 副本实验：路径改名、**追加路点**（7→8，内联坐标+旋转+序号）、**comp65 参数行同步追加**（7→8 行）三操作全持久化并通过重载验证；roundtrip PASS。

**字节写不变量（自洽四件套）——缺一即病件**：

| # | 不变量 |
|---|---|
| 1 | comp65 参数行数与行 f1 序列 = 路径路点数与 f1 序列**逐位平行**（增删路点必须双侧同步） |
| 2 | 路径 guid 必挂 f6 树（树 36/叶 4900）；新路径要补树叶 |
| 3 | 路点 f1 索引必须 < 实体表长度且语义指向锚实体（可共享、可指出生点；越界=坏） |
| 4 | 路点 `f1`（锚索引）在**单条路径内必须唯一且 ≥2**：重复 → 运行时建字典**撞键** → **加载协程中断、卡死**（人工核验；「对上了不等于能用」的标本，见 docs/04 §2.G） |

**整体替换律：适用（有条件）**。f32 body 自包含（重复 f1 条目），整体换库时保 guid 与树/comp65 一致即可；空 f32（0 字节）与字段缺席都是合法态，整库清空=写 0 字节 body 合法。**整体替换未经导入器实测** [?]。

**写入红线**：永不写运行中关卡 .gil；编辑器开着不写存档目录。路径域**无专属离线门禁**——verify 不认识 comp54↔comp65 平行不变量，写后必须按上表人工对账。

## 10. AI 写路径配方

```
① 放路点锚实体（可共享池；1:1 最稳）——实体本体停在 (0,2000,0)，不需要摆到路点位置
② f32 追加路径对象：guid 0x400 段续号 + 命名槽 + comp54（内联坐标/旋转/序号三真源）+ 变换槽（零默认）
③ f6 树 36 下补叶 {f1:4900, f2:guid}
④ 若挂怪物巡逻：comp65 路径引用 + 参数行与路点逐位平行
⑤ 引用序号与实体表逐一对账 + 往返一致性校验
```
