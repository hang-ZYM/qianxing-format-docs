# 模块库索引（mods/）

> 每个模块 = 一个可调用函数，内建四要素契约（前置检查 / 确定性执行 / 后验验收 / 回滚——
> 版本回滚语义由 `core.py` 包装器保证）。域怎么切、模块长什么样见 [06 模块化](../docs/06_模块化.md)。
> 状态位：✅ 生产已用 ｜ 🔶 代码与自测完成、真实导入待测 ｜ ⏳ 部分待锚。
>
> **本索引只列公开仓已发布的模块。** 按开放范围（[00 设计说明](../docs/00_设计说明.md) 第六节），
> 与**进程内操作 / 绕过机制**相关的能力不在公开范围，见文末「未开源边界」。

---

## core（基础设施 · 被调用，不是业务模块）

所有模块的运行时。三件事：

1. **统一调用流程**：前置检查 → 执行 → 后验 →（通过）写日志 + 落版本 /（拒绝）自动回滚——坏调用从构造上产生不了新版本；
2. **异常体系**：`PreconditionError`（前置不过 = 换路，不计失败）/ `ModuleRejected`（后验不过 = 自动回滚 + 计失败）/ 连续 4 次拒绝 → 抛换路信号（轮换律）；
3. **状态底座**：操作日志（`state/oplog.jsonl`，追加式）+ 版本制（`levels/<名>/v<N>.gil` + `current.json` 指针）。

## 图域

### graphgen.build —— 造图
- **吃**：GraphLogic（节点/边/文本，如"节点1=实体创建事件，节点2=打印[hello_loop]，1→2"）+ 图名 + guid
- **吐**：.gis 图文件
- **保证**：前置校验（kernel∈合法宇宙、边不悬空、text≤1000、guid∈0x4000 段）→ 产物过官方四连（roundtrip/verify/form_gate/oracle_gate），任一不过不交付
- **现状**：✅ 生产已用（产物与历史版本逐字节相等）

## 实体域

### entity.place —— 放置实体 ✅
- **吃**：aid + pos（可选 guid/yaw/scale；guid=None 走台账自动分配）
- **吐**：关卡新版本——f5 实体条目（合成）+ f6 tab3 叶 {200, guid}（统一注册律）
- **注册律**：怪物必须双注册（db type_id==1405 判别）；机关功能上非必需但统一注册 = 编辑器原生形态；怪物→0x408 段、机关→0x404 段（台账分配）
- **保证**：roundtrip + 双注册闭合 + 段位 + 实体数交叉核对；放置产物与其基底 diff = 仅 f5+1/f6+1
- **现状**：✅ 自测 38 条 PASS；真实导入/试玩 PENDING-GAME

### component.attach —— 挂组件 🔶
- **吃**：level_name + target_guid + cid + payload_spec（组件条目字节；或 `light_component(...)` 生成器）+ slot（5/6/7/8，默认 7）
- **吐**：关卡新版本——目标实体槽位追加/替换一个组件条目（插到尾 aid 字段 f8 之前）
- **保证**：前置（实体在位/cid 合法/不超限额）→ 后验（roundtrip + 读回在位 + 载荷逐字节一致 + 实体数不变 + trial_gate）
- **光源组件**（案例 #75）：f7 槽 cid38，载荷字段 f49；`light_component(name, radius, intensity, effect_range, color, attach, pos, rot, seq, group, angle)`
  （槽位语义 2026-10-15 订正：半径→变体 `f2`、强度→点 `f51.f3`／聚 `f52.f4`、角度→聚 `f52.f3`、生效范围→外层 `f501.f4.f2`；
  判别律：外层 `f501.f4` **带 `f1` ⇔ 聚光灯、不带 `f1` ⇔ 点光源**；`f51`=点光源／`f52`=聚光灯）
- **模型可见性组件**：f6 槽 cid8，载荷字段 f18；`visible_component(visible)` / `set_visible(level, guid, visible)`——f18 删 f1 = 不可见，`{f1:1,f501:1}` = 可见。*注*：f6 槽组件条目不携带 f2（与 f7 槽三字段形不同）；单位状态「隐藏角色」路字节面不可构造（编辑器 cid 未知且全档零配置实例），故走 f6#8 路。
- **现状**：🔶 自测 46 条 PASS；真实导入/试玩 PENDING-GAME

## 资产域

### asset.package —— 打资产包 🔶
- **吃**：实体/元件描述（最小形态 {aid, guid?, pos}）
- **吐**：.gia 资产包（实体合成 + 资产包包装）
- **保证**：后验 = trial_gate（实体形态门：染色正典/段位/形态合规）
- **现状**：🔶 自测 25 条 PASS（降级路径经 monkeypatch 重定向台账）；真实导入待测

### asset.deploy —— 部署资产包 🔶
- **吃**：.gia 文件
- **吐**：`Beyond_Local_Export/<名>.gia`（游戏资产导入界面只扫这里）
- **保证**：字节一致落盘（不一致删残件）
- **现状**：🔶 自测过；真实导入待测

### element.build —— 造元件（元件通道固化）✅
- **吃**：成员 BOM `[{aid, pos, rot?, scale?, color?, name?}]` + 元件名（+ guid/kind）
- **吐**：元件方言 .gia（元件组 = 主件 10008001 + 成员；或单体元件）
- **怎么做**：从官方 prefab 模板**从零构造**元件体（禁克隆）——无实例数据走模板直映（复现成功件），有 scale/color/rot/name 走合成实体体 → **槽位平移**（entity.f5→elem.f6 去实例态 cid19/52、f6→f7、f7→f8）；主件 cid61 摆放表填成员（guid/位置/aid/序号）→ 组 AssetBundle（f1 主件 + f2 成员 + f3 四段尾横杠 + f5 7.1.0）
- **保证**：前置（aid 在册 / guid 段位 / 成员数 < 上限）→ 后验（roundtrip + 元件体门 `trial_gate._check_element_body` + .gia 包门 `trial_gate._element_checks` + **名字组件门**），任一不过 `ModuleRejected` 不落版本
- **名字（案例 #72）**：主件体 f6 槽 **cid1 组件 → f11 → f1** = 编辑器「元件库」显示名；由 `set_body_name` 填真名（空则回退该 aid 的官方 prefab 名——10008001="元件组"）。读回用 `read_body_name`。
- **现状**：✅ 自测 **50 条 PASS**（最小元件复现 + 实例数据路 + 单体 + 负例 + 去重 + 名字组件 8 条）；真实导入已实证（案例 #71）

## 地形域

### terrain.patch —— 地形变更 ✅
- **吃**：cells（格键 100~119 + 字段白名单 layer/slope/material/water/path）
- **吐**：关卡新版本（TerrainPatcher 定点手术）
- **保证**：前置六检（格键/互斥律双向复核/层位/白名单/值域/基底在位）+ 后验六项（roundtrip/**块数交叉核对**/组交叉核对/键集守恒/变更块读回/**无辜块守恒**）——"只写变化块"事故由块数交叉核对拦截（逐格抽查抓不住）
- **约束**：基底必须有 f7 地形组；不支持造块/删块；只手术第一组
- **现状**：✅ 自测 33 条 PASS（含不变量事故端到端）

## 环境域

### env.set —— 设置环境（整包移植）🔶
- **吃**：level_name + preset（`very_dark` 夜晚 / `extreme_dark` 黑色 / `day` 白天 / `white` 白色——映射真实样本具名预设）
- **吐**：关卡新版本——f15 资产库新增/替换一条环境条目（`{f1:guid, f2:类型码 26, f4:命名组件, f4:数据组件}`，数据在 f75）+ f6 资源树 cat56 注册
- **保证**：前置（preset 合法 / 关卡有当前版本 / 真实样本图在位且含目标预设 / 基底能 roundtrip）→ 后验五项（roundtrip / 仅 f6+f15 变 / f6 旧条目守恒 / 读回 guid·类型码·名 / 载荷逐字节 == 真实样本预设）
- **现状**：🔶 自测 99 条 PASS（含 direct 直写与时间推进）；真实样本图需用户自备（见 `mods/config`）

### env.direct —— 字段直写（不整包移植）🔶
- **吃**：level_name + name + base（基底预设）+ 已解码字段（太阳/月亮亮度、受光色、天空背景色、环境颜色、云/远景色调、夜标记、雾配置、生效目标、时间曲线、关卡时间）
- **吐**：关卡新版本——取真实样本预设作基底，只覆写**已解码语义**的字段，其余字节不动
- **保证**：同 env.set 的后验面（逐字段读回交叉验证 + 未指定字段逐字节保真）
- **现状**：🔶 与 env.set 同组自测覆盖

## 关卡域

### level.mount —— 挂图 ✅
- **吃**：.gis 图文件 + 宿主实体 guid（S0 = 关卡实体 0x41400001）+ 挂载类别（服务器图 = 20000）
- **吐**：关卡新版本 .gil——四件事一次完成：图装进图库(f10) + 挂到宿主(f6.f13) + 注册进资源树(f6 树4 叶{800,guid}) + 实体注册面(tab3)
- **保证**：V0-V7 八项闭合检查——"图在库但没挂载 = 永远不执行"的坑在这里堵死
- **现状**：✅ 生产已用（真实样本三方闭合）

### level.deploy —— 部署关卡
- **吃**：关卡某版本 .gil + 命名（r<版本>）
- **吐**：`Beyond_Local_Export/<名>_r<N>.gil`
- **保证**：字节一致落盘
- **现状**：✅ 生产已用

### level.judge —— 运行判决
- **吃**：期望行为（expect_print）+ 超时预算 + 基线快照
- **吐**：Verdict（PASS/FAIL + 证据 + 地图 id）
- **三相轮询**：①等导入（镜像新地图）②等试玩日志（新 .gia）③解剖找打印字节
- **保证**：判决只认磁盘证据字节；超时/没导入/门没开如实报原因，绝不编造
- **现状**：✅ 判决 PASS

### level.checkpoint —— 落版本（手动挡）
- **吃**：当前 .gil
- **吐**：版本快照（v<N> + 指针更新）
- **用途**：大操作前存档、人工操作前后夹版本

### log.query —— 查操作日志
- **吃**：过滤条件（模块名/序号区间/成败）
- **吐**：日志条目（谁/何时/参数/验收结果/版本号）
- **用途**：编排器"做过的不重做"（completed 清单）；审计溯源（每个版本 = 哪几次调用）

## 测试通道（模块 → 通道的对应）

| 通道 | 模块链 | 用户动作 | 用途 |
|---|---|---|---|
| 冷交·关卡 | mount → deploy → (导入试玩) → judge | 导入 + 试玩 | 整关正式交付 |
| 冷交·资产 | package → deploy → (资产导入摆放试玩) | 资产导入 + 摆放 | 实体/元件交付 |

分工律：模块先在各自测试台验活，合格才进整关集成；整关的 L5 判决是归档验收正式条款。
（另有供单模块快速验活的**进程内热验通道**，按开放范围不公开，见下。）

## 未开源边界（说明边界本身就是专业）

本索引只列公开仓已发布的模块；以下能力**不在公开范围**（依据 [00 设计说明](../docs/00_设计说明.md) 第六节）：

- **进程内热写 / 热验通道**（编辑器进程内的图灌入与运行判决）——涉及进程内操作，不公开。
  公开仓以**文件侧交付链**（mount/deploy/judge 冷交）替代：产物落盘、由用户导入试玩、在磁盘证据上判决，
  全程不碰进程内。
- **关卡成品本身**（具体关卡文件、场景布局、坐标与数值表）——公开的是"怎么搭"的方法，
  不是"搭了什么"的产物。
- **环境域的完整档位**：`env.set` 只支持真实样本中已具名的少数预设，其余档位与生效机制的
  编辑器实测未完成（见模块 docstring 的遗留项）。

> 边界随公开范围变化而更新。凡未在「本索引」出现的模块名，均属未开源（而非不存在）。
