## 我们在做什么

对原神 UGC 编辑器（千星奇域 / BeyondEditor）的**数据格式与编辑器行为**做社区逆向研究，把观察到的知识整理成可以查阅的文档。面向想理解这套格式的开发者和研究者。

本仓库只包含格式知识、行为定律与测量数据（尺寸表）——不含任何游戏资产本体、可执行文件、账号数据，也不包含注入/修改工具。

内容分四块：

- **格式层**：文件容器的字节布局、数据模型、类型系统、变量体系
- **数据参考**：节点 / 实体 / 枚举的全量目录，实体尺寸（W/D/H）测量表
- **行为层**：编辑器如何装载、校验、改写内容；图在运行时的执行语义；从零构造一张合法最小图的正典
- **方法论**：我们怎么确认这些结论（docs/06）

每条结论标注证据分级：**[A]** 多源字节实证 / **[J]** 判例（可复现实验）/ **[P]** schema 注释推断 / **[C]** 目录数据（未运行验证）。
