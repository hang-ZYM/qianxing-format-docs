# 千星奇域 AI 创作知识库（qianxing-format-docs）

> **为 AI 而写的千星奇域（原神 UGC）创作知识体系**：22 册任务导向操作手册 + 27 卷深度参考
> + 离线工具链 + 实测数据。给 AI 这套文档和工具，它就能在你的验收下产出关卡。

## 这是什么

千星奇域（Miliastra Wonderland / BeyondEditor）的格式是二进制闭源的，编辑器只对手动操作者开放。
本仓库对它的**数据格式与编辑器行为**做了社区逆向研究，并把结果组织成一套**AI 可直接执行**的
知识体系——文档的每一层设计（任务导向 / 自包含 / 程序级步骤 / 真实示例）都为 AI 读者优化。

**人-机分工**：你负责创意、审美与验收；AI 读完这套文档完成产出。

**范围**：只含格式知识与测量数据；不含游戏资产本体、可执行文件、账号数据、注入或修改工具
（详见[诚实声明](#诚实声明)）。

**[C]** 目录数据。规则的主要提取方法（差分实验 / 负向测试 / 重保存对比）见
[docs/06 验证方法论](docs/06_验证方法论.md)与 [manuals/22 方法与经验](manuals/22_方法与经验.md)。

合成一张合法关卡图，见 [QUICKSTART.md](QUICKSTART.md)。

## 诚实声明

1. 所有结论标注证据分级：**[A]** 多源字节实证 / **[J]** 可复现实验 / **[P]** schema 注释推断 / **[C]** 目录数据（未运行验证）。
2. 编辑器带代码混淆，且**混淆名随版本重新生成**——涉及"类名/属性名"的结论绑定特定版本（格式样本基于 5.x 时代语料；docs/21 的活体行为定律实测于 CN 7.1 编辑器），版本更新后需按 06 篇方法重定位。
3. 本项目不做、也不鼓励违反游戏服务条款的行为；文档仅描述对本地文件格式与编辑器行为的**观察性知识**，不含任何工具、可执行物或操作配方。试玩与发布请走游戏官方通道。
4. 内部涉及的个人账号、本地路径等已全部脱敏。
5. **范围边界**：本仓库刻意限定于观察性知识（格式、行为定律、方法论）。以下类别**不属于发布范围**：网络通信协议的线级细节、编辑器进程内操作的具体方法、任何工具/脚本/注入配方。这类内容的公开可能违反服务条款或触及法律边界，也与本仓库"纯知识参考"的定位不符——请勿在本仓库寻求或索取此类内容。
