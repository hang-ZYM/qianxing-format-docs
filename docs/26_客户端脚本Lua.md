# 26 · 客户端脚本（Lua）——第三产出通道

> 证据：[A][J]。7.1 版引入客户端 Lua 5.3 后，千星成为**服务器节点图 + 客户端 Lua 的双语系统**：图管权威状态机与世界模型，Lua 管表现层、UI 与 2D 玩法。本卷讲三件事：**脚本怎么进文件**（wire 层，字节实证）、**怎么写**（API 面——官方文档的签名整理）、**怎么与图分工**。
> 对生成工具的意义：Lua 产出是纯文本——没有 varint、没有 guid 段位、没有接受性重写，是三条产出通道里生成成本最低的一条。

## 1. 双语架构总览

| | 服务器节点图（视觉语言） | 客户端 Lua 5.3（文本语言） |
|---|---|---|
| 角色 | 权威状态机 / 世界模型 / 变量写入 | UI 渲染 / 2D 玩法 / 交互采集 / 动画 |
| 产出载体 | protobuf 字节 | 明文 .lua 文本 |
| 生成成本 | 高（docs/03/22 全套约束） | 低（写代码即可） |
| 互通 | ←—— 信号 + 共享变量 ——→ | |

商城已出现大模型编写并通过官方审核上架的完整 Lua 关卡（2048）——脚本通道的 AI 可用性已被平台实践证明。

## 2. 脚本怎么进文件（wire 层）[A]

**脚本定义表 = 主 .gil 顶层 field 50**，每个条目一个脚本：

```
条目 = { 1: 映射ID(varint), 2: 脚本名, 3: "文件名.lua"(可带子目录), 5: lua源码全文(明文UTF-8) }
```

- 7.1 相对 7.0 的格式增量只有两个顶层字段：**field 1**（客户端域根引用，varint）与 **field 50**（脚本表）——其余完全兼容；7.0 旧件导入 7.1 仅触发升级器补 ClientUI 双根结构（实测样本 +31KB），不破坏；
- 单脚本体量上限高（实测样本最大 15.5MB——像素视频数据全塞 lua 的极端用法）；
- **双轨机制**：编辑器在存档目录旁维护 `external_lua_file/` 外置脚本文件（.gil 内嵌 + 外置文件双轨）；
- **BOM 风险**：外置文件可能带 UTF-8 BOM，平台日志警告 BOM 会导致 Lua 错误——生成脚本**不带 BOM**。

## 3. 0x4000 客户端域 ID 空间 [A]

| 子段 | 用途 |
|---|---|
| 0x40000001 ~ 0F | 脚本映射 ID（field 50 表） |
| 0x40000016+ | 控件树节点 guid |
| 顶层 field 1 | 客户端域根引用（样本值 0x4000000C） |

- **分配规则**：工程内递增分配、删除后不复用——生成时取未占用值即可；**克隆改件沿用原 ID 最稳**；
- 控件树（field 9.502）同一棵树承载模板定义层与运行时挂载层；属性键 64/74 = 脚本挂载（引用映射 ID）——**脚本与控件的绑定就在这两个属性键上**。

## 4. 出件配方（六步）[J]

1. 取 7.1 底座（可运行样本或自建存档）；
2. 替换/新增 field 50 条目（lua 明文直接写入，varint 长度重算）；
3. 控件树属性键 64/74 的脚本引用指向新映射 ID；
4. 顶层 field 1 保留底座原值；
5. 尾部版本字段写 `CNRELWin7.1.0`（老版本号会触发升级器重写）；
6. 离线验证 → 官方导入。

平台级实证 [J]：f50 注入件被编辑器收编为新存档，映射 ID 与 lua 内容逐字节保留，客户端脚本资源管理器里可见可打开。

## 5. 运行环境与 API 面

（本节为官方《客户端控件 API 文档》的整理；全量签名见 `data/client_api.d.lua`——IDE attach 可得补全。）

- **Lua 5.3 沙箱**：禁 `io.*`、`coroutine.*`、`string.dump`、`os.*`（留 time/date/clock/difftime）、`debug.*`（留 traceback）；补 `math.isnan/isinf`；
- **生命周期七钩子**（运行时按固定名查找调用）：`OnInit / OnStart / OnEnable / OnDisable / OnUpdate(不受时停) / OnLevelUpdate(受时停) / OnDestroy`；
- **事件驱动，无同步等待**；传送/重连时控件全销毁，恢复逻辑自理；
- **动态 UI**：`game.InstantiateClientUIControl(prefabIndex, parent)` 仅模板父节点下可动态建；TextBox.text 可写；容器开 `showCursor` 即纯鼠标 2D 玩法；
- **两套 UI 隔离**：服务器控件（旧体系）的模板索引 Lua 拿不到；客户端控件只活在控件容器画布或控件模板里。

## 6. 图 ↔ Lua 信号互通（docs/15/23 的 Lua 侧半边）

| 方向 | 机制 |
|---|---|
| Lua → 服务器 | `game.ServerSignal(name):AddXxx(...):SendSignal()`（18 种参数类型；联机下行延迟 ≥100ms） |
| 服务器 → Lua | 图节点【发送客户端脚本信号】→ Lua `script:RegisterServerSignalHandler(name, cb)`（注册须在 OnInit 内，docs/23 §7） |
| 共享状态 | 自定义变量：`GetGlobalCustomVariableValue` + `RegisterCustomVariableChangedHandler`（支持列表/字典/结构体）——**自定义变量是双语间唯一的状态桥**（docs/05 §3） |

最小桥接范式（官方过审的掉线检测样本）：8 秒心跳 ServerSignal → 服务器图 → 变量回读。

## 7. 双语分工判定（什么逻辑放哪边）

四维判定：**权威性**（状态归谁）→ **时停敏感**（要不要跟随关卡时停）→ **重连存活**（重连后要不要重建）→ **延迟容忍**（能不能等 ≥100ms）。

- 权威状态、变量写入、世界与实体操控 → 服务器图；
- 渲染表现、本地交互、动画 → Lua；
- 已知平台 bug 的官方绕行：服务器控件的 Button/Toggle 选项文字空白（客户端渲染层问题）——**UI 一律走客户端控件 + Lua**。

实例参照（商城 7 件样本谱，内部研究库）：中国象棋含 AI（2 脚本 97KB）/ 坦克大战（6 脚本模块化最正规）/ BadApple（15.5MB 极端）/ 2048（同行 AI 作品）/ 纯 2D 模板（7.0/7.1 A/B 对照对）/ 掉线检测（最小桥接范式）/ 全像素角色库（122 脚本）。
