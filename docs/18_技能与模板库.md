# 18 · 技能与模板库（f15/f16）

> RPG 模板(1966) × 空白图(2003) 对照 + 官方文档。

## 1. f15 = 默认模板库（不是技能库）

f15 在所有地图（包括空白图）都有 ~8KB——它是**编辑器出厂自带的默认模板集**：

| 子项 | guid | 名称 | 大小 | 内容 |
|---|---|---|---|---|
| [0] | 0x42c00001 | **背包模板** | 46B | f4{f1:42, f55:引用} |
| [1] | 0x46c00001 | **环境配置** | 2428B | f4{f1:70, f75:2391B配置} |
| [2] | 0x41000001 | **自定义职业** | 1703B | f4{f1:8→f16, f1:9→f17(1481B), f1:10→f18, ...} |
| [3] | 0x41400001 | **自定义成长曲线** | 3919B | f4{f1:12, f20:3873B} |
| [4] | 0x42000001 | **选项卡显示用道具** | 111B | f4{f1:39, f49:64B} |

**修正旧认知**：之前知识库说 f15/f16 是"职业/玩家模板+技能库"——实际上 **f15 是跨域默认模板集合**（背包+环境+职业+成长曲线+道具），技能只是其中"自定义职业"子项的一部分。

## 2. f16 = 自定义模板增量

f16 在空白图为空，在 RPG 模板有 1 条（91B）——用户**自定义添加的模板**：

```
f16.f1 = {
  f1: 1107296257 (guid, 0x42000001段=道具)
  f2: 1107296257 (同guid)
  f3: {f1:39, f49: {f1: {f1:9999, f3:1, f4:4202, f5:4301, f6:引用5B, f502:1}}}
}
```

内层数字：9999=物品id?, 4202/4301=道具/图标id?, 指向一个具体的自定义道具模板。

## 3. 结构定律

**f15/f16 的每个子项 = `{f1: guid, f2: guid, f3/f4: 内容区}`**，内容区的每个 f4 是 `{f1: 组件ID, f(组件ID+10): 载荷}`——和实体组件系统**同构**！

这验证了母范式四（内容三层）：模板库、实体、图都是"容器+组件"的统一架构。

## 4. 技能在哪里

技能不在 f15/f16 的顶层——它们藏在"自定义职业"(f15[2]) 的深层嵌套里（f17 有 1481B），或者在编辑器的技能编辑器中单独管理后引用到职业模板。

**官方文档关键数字**：
- 职业可配置技能上限 **50**
- 自定义技能最大数量 **1000**
- 技能资源数量上限 **2000**
- 技能动画数量上限 **100**

这些数字表明技能系统是一个**大型独立子系统**（编辑器有专门的"战斗预设"页签），不是简单地存在 .gil 的一个字段里。

## 5. 未解

- f15[2] "自定义职业" 内 1481B 的 f17 具体结构（技能列表? 属性面板?）
- 技能编辑器的完整数据流（在哪编辑、存到哪、怎么被节点图引用）
- 成长曲线 3873B 的数据格式
- guid 段位：0x42c=背包, 0x46c=环境, 0x410=职业, 0x414=成长曲线, 0x420=道具

## 6. 与其他系统的关系

| 系统 | 位置 | 关系 |
|---|---|---|
| 自定义职业 | f15[2] | 定义玩家可用职业（属性/技能/外观） |
| 技能 | 职业模板内 | 被节点图的技能节点调用（392 技能节点调用时） |
| 成长曲线 | f15[3] | 怪物/造物的等级成长（关联配怪系统） |
| 背包模板 | f15[0] | 定义背包初始内容（关联物品/经济系统） |
| 环境配置 | f15[1] | 地形的视觉层（顶/侧/地面色、天空、太阳月亮） |
