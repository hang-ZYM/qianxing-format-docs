# 05 · 变量系统（三层）

千星的变量分三层，各有声明处、作用域与访问节点 [A/J]：

| 维度 | 实体变量 | 图黑板变量 | 自定义变量 |
|---|---|---|---|
| 声明位置 | 实体 f7#1 组件 | 图 f6 (GraphVariable) | 地图主 .gil 顶层 f35 注册表 |
| 作用域 | 单实体 | 单图 | 全地图 |
| 访问节点 | 属性/行为类节点 | 设置/获取图变量节点族 | 取/设自定义变量节点族（按名字符串寻址） |
| 类型表示 | 内嵌类型定义 | f3 base_type + f7/f8 容器子类型 | 注册表条目内 |

## 1. 实体变量（f7#1）[A]

挂在实体 AI 属性槽上的命名属性，带中文显示名（编辑器 UI 可见）：

```
f7#1 = {1:1, 2:1, 11:{1:{
  2: 变量名(utf8),          # 如 "是否显示"
  3: 类型,                  # 4=Bool, 6=字符串族...
  4: {1:类型, 2:{1:类型,2:0}},
  5: 值,                    # 如 1=真
  6: {1:类型, 2:0}
}}}
```

## 2. 图黑板变量（GraphVariable, 图 f6）[A]

图内共享数据的局部变量池，随图保存：

```
{f2: 变量名, f3: base_type, f4: 初始值(TypedValue), f5: is_public, f7: 容器key类型, f8: 容器value类型}
```

实测样本（RPG 模板地图）：`"对话交互按钮"{Int, public}`、`"选项控件列表"{IntList(8)}`、`"空列表"{StringList(11)}` 等。

## 3. 自定义变量（地图注册表 f35）[J]

结构见 docs/03 §3。要点：

- 声明条目按**字典序**排列；
- 图内取变量节点以**变量名字符串**寻址，名字不在注册表 = 运行时读不到；
- 注册表**不可直接字节级修改**（追加合法条目也会解析失败），只能模型级修改；
- 新建地图的注册表为空壳，变量需在编辑器变量面板创建（或走模型级写入）。

## 4. 运行时语义提示

三层变量的读写节点各成家族（取/设/变更触发），跨层不通用。图执行时栈上还有 `LocalVarRef(16)` 与 `VarSnapshotRef(28)` 两个运行时引用类型（用于回滚与实体销毁后访问原始数据）[P]。

**黑板变量的运行态（v1.3 实证扩充，详见 docs/23 §5）**[J]：图 f6 声明池在装载时转换为按**变量名索引**的运行态池；读/写节点运行时按名字符串寻址（与自定义变量同构）；变量名与运行时值在图执行记录中逐条可见。**图内变量名是运行时契约**——改名等于改寻址，所有引用点必须同步。
