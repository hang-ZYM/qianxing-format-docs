> 证据：[A] 字节实证（266 件编辑器导出包反向提取 + 266 件自建包回建对照，2026-10-05）
> 状态：提取方向已规模化验证；渲染方向以 266 件示例全量出图验证。
> 工具：`src/gia_extract.py`（.gia → 结构化清单）、`src/archdraw.py`（BOM → 施工图 SVG）。

## 1. 定位

27 卷解决了"把实体打进 .gia 导入游戏"；本卷解决**回流**：编辑器里改好的东西导出成 .gia 后，
如何还原成结构化数据（BOM），从而可 diff、可入库、可重建、可出图。

**BOM（Bill of Materials）** = 一批实体的生产数据表，每件一行：

```json
{ "id": 1, "asset_id": 10009001, "role": "台阶一级",
  "position": {"x": 0, "y": 0.09, "z": 0},
  "scale": [12.9, 0.26, 5.0],
  "rotation": {"x": 0, "y": 0, "z": 0},
  "color": [0xA8A090, 0x20, null], "layer": "基座层" }
```

- 坐标系自选（示例用"原点=建筑中心地面，+X东 +Y上 +Z南"），position=构件几何中心（米）
- rotation=度；scale=乘以资产原生尺寸的系数（原生尺寸见 24 卷）
- color=(rgb24, alpha, blend) 对应实体覆盖色配方（27 卷 §5）

## 2. 反向提取：字段路径（gia_extract.py 的依据）

27 卷 §3 的实体包装再往里走三层：

```
实体消息 {
  f1: guid (varint)
  f8: asset_id (varint)
  f5: 行为组件[] —— 其中名称组件 = { f1:1, f11: { f1: 名称UTF-8 } }
  f6: 编辑器组件[] —— 其中变换组件 = { f1:1, f11: {
         f1: { f1:x, f2:y, f3:z }        位置 (f32)
         f2: { f1:X°, f2:Y°, f3:Z° }     三轴旋转 (f32, 度; 零值省略)
         f3: { f1:sx, f2:sy, f3:sz }     缩放 (f32)
     } } }
}
```

实测注意（[A]）：
- 导入后游戏会**重编号 guid**（用户段内重新分配），并给实体追加若干行为/编辑器组件
  （如 GI_RootNode、MPActionGroup）——提取时按字段路径取值即可，不受影响
- 位置存在 ~3cm 级的网格吸附 rounding，diff 时阈值取 5cm
- 提取侧不改任何文件，纯读取

## 3. 导入器行为补充判例 [J]

- **额外碰撞组件（12 卷 f7 槽 cid8/配载 f18）的碰撞体定义在实体本地空间，会被实体
  scale 二次放大**：给 scale=3.3 的实体挂 3.3m 碰撞盒，实际生效 10.9m。实测后果：
  拱门两侧墩体的碰撞盒横跨门洞，形成"空气墙"。要精确碰撞须按 目标尺寸÷实体缩放
  换算并试玩验证；未验证前大型景观建议零碰撞。
- 导入后染色（comp22）保留；名称保留（UTF-8 完整回读）。

## 4. 案例研究：旋转拼装拱（示例资产的拱券构造）

圆弧拱在"只有原始几何体"的约束下用**放射状旋转长方体**拼装（三轴旋转 27 卷 §4）：

- 拱 = 正圆，圆心在起拱线上；每块券石放在 φ 角位置，`rot_z = 90° − φ`（石宽贴弧切向）
- **闭缝法则**：石宽 ≥ 弧长槽位 2πr/N（宁可重叠不可留缝——缝隙在拱腹侧最显眼）
- 视觉平滑阶梯（r≈3m 时）：12 块/圈弦高差 25mm → 24 块 6mm → 48 块 1.5mm；
  48 块为性价比顶点
- 几何边界：开口拱无法用圆盘做光滑内缘——圆心在起拱线的半圆，任何覆盖拱肩的
  实心圆盘必然填死门洞（勾股可证）；分段拼装是原始件体系下的唯一解

## 5. BOM 驱动制图（archdraw.py 的画法原则）

图纸 = BOM 的投影，不是手工画。两种画法按图种切换：

- **立面/平面 = 聚合画法**：墙体合并成整体面层、拱画同心弧带+放射缝、柱画分段式，
  配尺寸线/标高/图例。反例教训：逐件画色块矩形，178 个色块 = 视觉噪声
- **大样 = 逐构件画法**：详图就要一块一块画（角度/尺寸/旋转量逐块标注）
- 全部几何从 BOM 推导（标高查角色件、半径拟合券石、缝线数量=件数）——改 BOM，
  图纸一条命令自动跟随
- 立面投影去重条件：沿视线方向（如 z>0），**不是 x>0**——后者会删掉左右镜像件

## 6. 工具用法

```
# .gia -> 实体清单 JSON
python -m gia_extract 文件.gia --json out.json

# BOM -> 四张施工图 SVG（正立面/侧立面/平面/拱券大样）
python -m archdraw examples/凯旋门_圣地_BOM.json --out out/
```

示例：`examples/` 下为 266 件凯旋门（用户定版）BOM 及 archdraw 生成的四张图。
合成方向（BOM → .gia）依赖内部维护的样本库，不在本仓库发布范围内。
