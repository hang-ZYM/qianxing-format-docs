## 3. 时间渐变系统

每个颜色组(f26/f30-f34)内部有 **多个关键帧**：
```
f3 × N = {f1: ARGB颜色, f2: {f1: 通道编号, f2: 参数}}
```
f2 的 f1 值（4-13）可能是渐变通道或时段索引。这是**随时间自动切换**功能的字节基础（官方文档："启用随时间自动切换时，可查看该参数在对应时间点的配置值"）。

## 4. 组件定律修正

**勘误（2026-10-04）**：本卷原记"组件 70 → f75，定律不适用于模板库"——该修正不成立；同卷组件 1→f11 符合定律自证。组件 70 按定律应为 f80，f75 系原始解码误记，待对字节复核。

**修正**：组件定律（配置字段 = ID+10）适用于**实体四槽**（f5/f6/f7）的组件，**不适用于模板库**（f15）的组件。模板库的组件-字段映射可能是独立的 schema 定义。

## 6. 范式意义

环境配置是**表现层**的核心——它控制"这个世界看起来是什么感觉"。存在模板库里（f15）而非直接在场景数据里，说明它是**可复制的预设**（不是每个关卡独有，而是可从模板库选择应用）。

连接母范式四（内容三层）：场景层（地形+实体）是物理世界 → 环境配置是视觉滤镜 → UI/音效是交互层。
