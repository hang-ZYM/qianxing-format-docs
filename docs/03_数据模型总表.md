# 03 · 数据模型总表（字段级）

> 本篇是核心参考。证据分级：[A]字节实证 / [J]判例 / [P]schema注释推断 / [C]目录数据。
> schema 骨架参考上游 `gia.proto`（Wu-Yijun 逆向），本项目补齐了行为语义与大量字段实测。

## 0. 总关系图

```
容器(.gil主 / .gis分片)
 └─ 关卡文档消息（两者同构）
     ├─ f5 实体列表 ──→ 关卡实体 ×N（六槽模型, §1; f4为定义/模板区待定）
     ├─ f10 图库 ──→ 图容器 ×N ──→ 图(NodeGraph, §2)
     │                                ├─ 节点(NodeInstance) ×N
     │                                │    └─ 引脚(PinInstance) ×N
     │                                │         ├─ 值(TypedValue) ← 参数
     │                                │         └─ 连线(NodeConnection) ×N
     │                                └─ 黑板变量(GraphVariable) ×N
     └─ f35 变量注册表 ──→ 条目{名, 标志} ×N（地图级自定义变量声明, §4）
```

连线存储的**双约定** [A]（极易弄反）：
- **数据线**：存在**目的端** IN_PARAM 引脚的 connections[]，指向{源节点, 源OUT_PARAM#n}
- **执行线**：存在**源端** OUT_FLOW 引脚的 connections[]，指向{目的节点, 目的IN_FLOW#n}

## 1. 实体（六槽模型）[A]

实体位于关卡文档 **f5（实体列表）**，每条 = 一个 f1 包裹的实体消息（16 张实测地图全量验证）。

```
关卡实体 = {
  f1: guid              # 关卡内唯一; 0x404带=gadget, 0x408带=monster
  f2: 来源标记(双形态)    # {1:aid, 2:1} = 资产面板原生摆放
                        # {1:模板guid}   = 原型实体实例化(蓝图复用系统)
  f5: [行为组件]
  f6: [编辑器组件]       # f6#1 = 位置组件 {11:{1:pos, 2:rot(度), 3:scale, 501:-1}}
  f7: [AI属性组件]       # f7#1 = 实体变量(命名属性, 见docs/05)
  f8: aid               # 资产id(对应prefab库)
}
```

槽内组件语义摘要 [A]：

| 槽 | 常见组件id | 已知语义 |
|---|---|---|
| f5 行为 | 1,111,19,13,14,38,40,52; 触发器族3/5/110 | 14=动作组; 40=子实体引用 |
| f6 编辑 | 1,3,6,7,4,5,11,17; 15(触发器) | 1=位置; 7=交互参数; 11=挂点树(GI_RootNode); 4/5=标志位 |
| f7 属性 | 1,3,18,6,14,19,40,21,22,32,17,46 | 1=命名属性; 18=受击/倒地特效钩子 |

## 2. 节点图

### 2.1 NodeGraph（图）

| 字段 | 类型 | 语义 | 证据 |
|---|---|---|---|
| f1 | ResourceLocator | 图身份（f5=图id，全用户空间唯一，如 0x40000001） | [A] |
| f2 | string | 显示名 | [A] |
| f3 | repeated NodeInstance | 节点列表 | [A] |
| f4 | repeated | 端口声明/接口映射（复合节点） | [P] |
| f5 | repeated | 注释（可吸附节点） | [P] |
| f6 | repeated GraphVariable | 黑板变量池（docs/05） | [A] |
| f100 | int32 | 入口槽索引 | [P] |
| f101 | float | 求值间隔（过滤器） | [P] |

### 2.2 NodeInstance（节点实例 = 一次函数调用）

| 字段 | 类型 | 语义 | 证据 |
|---|---|---|---|
| f1 | int32 | index（图内句柄，应稠密） | [A] |
| f2 | ResourceLocator | **shell_ref**（UI外壳：节点长什么样） | [A] |
| f3 | ResourceLocator | **kernel_ref**（逻辑内核：节点怎么跑）。泛型节点此处=具体实例化的 kernel id；缺省=未决议（类型未选的合法状态） | [A][J] |
| f4 | repeated PinInstance | 引脚 | [A] |
| f5/f6 | float | 画布坐标x/y（**网格单位**，非像素） | [J] |
| f7 | Annotation | 用户备注 | [P] |
| f8 | PinSignature | 入口上下文声明 | [P] |
| f10 | repeated | using_structs 结构体依赖 | [P] |

ResourceLocator 惯用形态：`{1:10001(Origin), 2:20000(Category), 3:22000(Kind=SYS_CALL_STUB), 5:runtime_id}`——**runtime_id 即节点目录 id**（558 词表），泛型实例化后为 Variants[].KernelID。

### 2.3 PinInstance（引脚 = 形参）

| 字段 | 类型 | 语义 | 证据 |
|---|---|---|---|
| f1 | PinSignature | shell_sig：UI槽位对位 | [A] |
| f2 | PinSignature | kernel_sig：内核参数槽对位 | [A] |
| f3 | TypedValue | 值（实参） | [A] |
| f4 | int32 | 类型码（**裸 varint ServerTypeId**，见 docs/04） | [J] |
| f5 | repeated NodeConnection | 连线 | [A] |
| f6 | PinSignature | 元数据绑定（RPC/Topic） | [P] |
| f7 | int32 | 动态引脚持久ID | [P] |

**PinSignature = {f1: kind, f2: index}，index 一律 0 基，=0 时省略 f2** [J]（历史上曾被误判为 1 基，原生样本对照翻案）。

kind 枚举：1=IN_FLOW, 2=OUT_FLOW, 3=IN_PARAM, 4=OUT_PARAM, 5/6=META(RPC/Topic), 13-16=结构体操作 [P]。

编辑器原生方言会物化 OUT_PARAM 引脚；第三方生成的内容不物化输出引脚也能正常显示连线（编辑器按 kernel 签名解析源引脚）[J]。

### 2.4 TypedValue（值对象）

| 字段 | 类型 | 语义 | 证据 |
|---|---|---|---|
| f1 | enum WidgetType | UI控件类型 | [A] |
| f2 | int32 | is_value_set（0空/1已填） | [A] |
| f4 | TypeDefinition | 类型元数据 | [A] |
| f5 | InstanceTracker | 结构体实例追踪 | [P] |
| f101-f112 | oneof | 实际值存储（见下表） | [J] |

**storage 全家表**——所有 storage 成员都是**包裹消息**，不是裸标量（编成裸标量会被静默丢字节 [J]）：

| 字段 | 值 | 包裹消息 | 常见Widget |
|---|---|---|---|
| f101 | id | Id{f1:int64} | ID_INPUT(1) |
| f102 | int | Int{f1:int32} | NUMBER_INPUT(2) |
| f104 | float | Float{f1:fixed32} | DECIMAL_INPUT(4) |
| f105 | string | String{f1:utf8} | TEXT_INPUT(5) |
| f106 | enum | Enum{f1:int64} | ENUM_PICKER(6) |
| f107 | vector | Vector{f1:{x,y,z}} | VECTOR_GROUP(7) |
| f108/109 | struct/list | 嵌套TypedValue | STRUCT_BLOCK/LIST_GROUP |
| f110 | 多态值 | PolymorphicValue{f1:chosen_type_index, f2:actual(TypedValue)} | TYPE_SELECTOR(10000) |
| f111/112 | pair/map | 键值容器 | MAP族 |

**val_poly(f110) 是泛型/变体引脚的值形态**：chosen_type_index 对应节点目录 Variants[].TypeSelectorIndex，默认 0 时省略 [J]。

### 2.5 NodeConnection（连线）

`{f1: 对端节点index, f2: 对端shell_sig, f3: 对端kernel_sig}` [A]
对端引脚 index 0 基；类型错配的连线在加载时被静默丢弃（docs/02 定律5）。

对端 sig 的 kind 语义（默认图模板实例化，详见 docs/22 §3）：执行边的对端 kind=1（IN_FLOW），数据边的对端 kind=4（IN_PARAM）；shell 与 kernel 同值，index=0 时省略。

> **最小图正典**：一张被编辑器接受的最小图需要哪些元素、边编码的完整实例，见 docs/22。

### 2.6 GraphVariable（图黑板变量）[A]

`{f2: 变量名, f3: base_type(ServerTypeId), f4: 初始值(TypedValue), f5: is_public, f7/f8: 容器key/value子类型}`

## 3. 地图变量注册表（主 .gil 顶层 f35）[J]

结构：`f35 → f1 → f1 → repeated 条目`，每条 `{f1: 名字(字符串), f501: 标志(bytes)}`，字典序排列。
地图级"自定义变量"的**声明处**；图内"取自定义变量"节点按名字引用。

**⚠ 该区域不可直接字节手术**——在合法文件中追加逐字节复制的合法条目都会导致解析失败（自实现序列化器的嵌套约束）。合法修改路径只有模型级（解析为对象 → 集合 Add → 重新序列化）[J]。

## 4. 编码速查（写字节前必读）

1. protobuf 高字段号（>15）的 tag 必须用 varint 编码，单字节会炸 [J]
2. 节点 f4 是"单个引脚"（repeated 字段），不能再内层包裹 [J]
3. 引脚 sig 索引 0 基，=0 省略 [J]
4. storage 全是包裹消息 [J]
5. 画布坐标网格单位 [J]
6. 数据线/执行线存储侧别相反 [A]
