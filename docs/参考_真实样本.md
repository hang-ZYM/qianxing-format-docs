# 参考 · 真实样本索引

> **读者为什么需要知道这个** —— 本仓有一条方法论是「结论只能从真实样本长出来」（[12 纪律](12_纪律.md) 第四节）。这份索引做的是这件事的账：**每一条结论靠的是什么样本、样本属哪一类、它证到了哪一级**。不读它，你只知道一条结论「标了字节实证」，却不知道它是从哪个真实样本读出来的、这份证据够不够硬。

**前置**：[04 对齐](04_对齐.md) 第三节（一条映射怎么加进去的四步法）、[12 纪律](12_纪律.md) 第四节（真实样本优先）。术语沿用 [参考_术语表](参考_术语表.md)。

## 一、这份索引要说什么

本仓把「结论的来源可查」当成一样核心资产。这份索引就是它的账本。

**它记的是证据类型，不是文件。** 每一条样本一律用**描述**表示——「一次编辑器内手动操作前后的 diff」「一张官方地图作者自命名的预设对比」「一次实机核验」——描述到「这类证据存在、它证到了哪一级」就够了。**它的价值在「证据类型」，不在「是哪个文件」。**

为此，下列内容**一律不进本索引**：

- 关卡成品文件名；
- 用户存档 id / 路径 / uid；
- 内部绝对路径；
- 反编译的混淆类名。

（证据等级沿用 [00 设计说明](00_设计说明.md) 原则 3 四档：**字节实证**（从真实文件里读出来的）/ **官方文档** / **人工核验**（人在编辑器或实机里亲眼确认过的）/ **推断**。）

**样本的两种来源**（[04 对齐](04_对齐.md) 第三节第 1 步）：一是在编辑器里**原生做一次**（编辑器原生创建的产物是权威基准）；二是从现成关卡里**找一个已经带这个功能的样本**。本索引两类都收，并在描述里区分「编辑器内操作 diff」与「现成样本对拍」。

## 三、几点说明

- **本索引不是「样本库」。** 它不存放任何样本本身，只登记「哪一类样本证明了哪一级结论」。要复现一条结论，按 [04 对齐](04_对齐.md) 第三节四步法自己造一次样本即可——本索引只告诉你该造哪一类。
- **负面结果也算样本。** 第 30 条记的是一次「零命中」：普查全部样本、某面板项一次都没被用到，于是「抽不到」本身成了一个有出处的状态。这和「还没试」是两回事（[12 纪律](12_纪律.md) 第五节）。
- **等级会随取证升格。** 表里一条今天标「人工核验」的，可能下一次单变量实验后升成「字节实证」；一条今天只到「推断」的（本索引一律不收「推断」，因为推断没有样本），等真实样本到位才进这张表。升格规则见 [04 对齐](04 对齐.md) 第三节第 4 步。
- **没进的样本**：任何以「平台保存过的第三方内容」归纳出的规律都不进本索引——那是循环论证，不算真实样本（术语表「真实样本」）。
- **与未完成项台账互为两面。** 本索引记「靠什么定了什么」；同一件事若还缺一次取证，则记在 [参考_未完成项](参考_未完成项.md)。一条未完成项取证完成、升进正文时，它对应的样本就该落进本索引。
