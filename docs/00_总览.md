# 00 · 总览：千星 AI 创作知识库

> 本卷是仓库阅读入口。先在此建立全貌，再按需进入各卷/各手册。
> 逻辑主线：平台架构（数据在谁手里）→ 内容组件 → 编辑器行为 → 读/写/交付/验证 → 边界。

## 一句话

**为 AI 而写的千星奇域创作知识体系**——给 AI 这套文档和工具，它就能在你的验收下产出关卡。

## 平台全景

```
云端（权威存档）
  │ 推送                        ▲ 保存
  ▼                             │
游戏进程（实体/地形/关卡数据）────┴──拉起编辑器
  │ .gil（游戏侧持久化）              │
  ▼                                  ▼
本地 BeyondLocal 目录            编辑器（仅节点图）
                                     ↑ 进程内通道（研究用，不入库）
程序侧：读/写 .gil/.gis/.gia 文件（qxfmt）+ .gia 官方导入
```

**两条架构发现**（一切通道设计的根据）：
1. 实体/地形在**游戏进程**；编辑器只编辑**节点图**——不存在万能干预点
2. 编辑器**不读 .gil 文件**——数据经推送进入会话

## 验证方法（三层闭环）

```
① 写入自校验（qxfmt 往返一致性，每次写文件自动执行）
② 规则校验（qxfmt verify——已积累实证规则的离线检查）
③ 编辑器终审（装载行为为最终裁决：导入观察 + 重保存对比）
```

规则从③回填②——每条新规则使一类错误此后可离线拦截。
详见 [06 验证方法论](06_验证方法论.md)与 [manuals/17](../manuals/17_验证与日志手册.md)。

## 边界（诚实清单）

- 客户端脚本运行时验证进行中（最小闭环已证，量产路径为开放问题）
- .gia 同 guid 重复导入行为未测
- verify 是规则面校验，不等于装载判定
- 本仓库不含进程内工具与游戏资产（[README 范围声明](../README.md)）
