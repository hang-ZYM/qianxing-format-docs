# 17 · 地形系统（f7 深挖）

> 官方文档 × 字节解码 × 空白图/RPG模板对照。

## 1. 官方语义（文档全文提取）

- **最小操作单位** = 单层地块，**5×5 世界单位，层高 2.5**
- **材质**：共计 7 种地块材质（草/石/冰/石化等）
- **笔刷操作**：创建(增高x层)/删除(降低x层)/抹平(指定高度)
- **斜坡**：在已有地块顶部创建，正向/向左/向右
- **水体**：地块顶部一层变为水体
- **路径**：地块顶部表面创建路径
- **地形对象**：所有相连地块形成一块地形，不相连的形成多块
- **环境配置**（独立于地块）：天空/太阳/月亮/雾/环境色（顶/侧/地面三色）

## 2. 字节结构（已解码 ✅）

```
f7 (地形区)
 └─ f1 (地形对象) × N
     ├─ f1: guid (如 1073741825 = 0x40000001)
     ├─ f2: 名称字符串 (如 "地形01")
     ├─ f3: 变换 {f1:{x,y,z 位置f32}, f2:{旋转}} ← 地形锚点
     └─ f4 (地块) × N
         ├─ f1: 格子坐标 = (x << 16) | z   ← 编码实锤
         ├─ f2: 层数 (1=一层, 每层2.5世界单位)
         └─ f3: 材质类型 (缺省=默认材质)
```

## 3. 坐标编码（已验证 ✅）

**f1 = (grid_x << 16) | grid_z**

| 地块 | f1 值 | grid_x | grid_z |
|---|---|---|---|
| 空白图[0] | 6553700 | 100 | 100 |
| 空白图[1] | 6619236 | 101 | 100 |
| 空白图[399] | 7798903 | 119 | 119 |

空白图默认地形 = **20×20 格**（grid_x 100~119, grid_z 100~119），全部层 1，默认材质。

**世界坐标换算**：
```
world_x = terrain.f3.f1.f1 + (grid_x - anchor_x) * 5
world_y = terrain.f3.f1.f2 + layer * 2.5
world_z = terrain.f3.f1.f3 + (grid_z - anchor_z) * 5
```
空白图锚点 (-547.5, -2.5, -547.5)，地块 (100,100) → 世界 (-547.5+0, -2.5+2.5, -547.5+0) = (-547.5, 0, -547.5)。

## 4. RPG 模板的地形

RPG 模板(1966)只有 **9 个地块**（3×3 小平台），grid (99~101, 99~101)，全层 1，默认材质。这是编辑器里手工放置的一小块地面。

## 5. 与官方功能的映射

| 官方功能 | 字节对应 |
|---|---|
| 创建地形 | 新增 f7.f1(地形对象) |
| 笔刷创建(增高) | f4 新增地块 or 已有地块 f2+1 |
| 笔刷删除(降低) | f2-1 or 删 f4 |
| 抹平 | 所有选中地块 f2 设为指定值 |
| 斜坡 | 待挖（可能是 f3 或专用字段） |
| 水体 | 待挖（可能是 f3 材质变体或专用字段） |
| 路径 | 待挖（可能是 f3 或 f4 附加字段） |
| 地块材质 | f4.f3（7 种材质的枚举值待定） |
| 地形位置/旋转 | f7.f1.f3(变换) |
