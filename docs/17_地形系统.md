# 17 · 地形系统（f7 全解码）

> 证据：[A]（商城语料 423 图、19 万地块、767 地形组全量普查 + 方向统计判决；空白图/RPG 模板对照；官方文档语义互证）。v2（2026-10-03）：v1 的三大"待挖"（斜坡/水体/路径）全部破译，多地形对象结构定案。

## 1. 官方语义（文档全文提取）

- **最小操作单位** = 单层地块，**5×5 世界单位，层高 2.5**
- **材质**：7 种地块材质（草/石/冰/石化等）
- **笔刷操作**：创建(增高x层)/删除(降低x层)/抹平(指定高度)
- **斜坡**：在已有地块顶部创建，正向/向左/向右（UI 相对方向；wire 为绝对四向，见 §3）
- **水体**：地块顶部一层变为水体；**路径**：地块顶部表面创建路径
- **地形对象**：所有相连地块形成一块地形，不相连的形成多块
- **环境配置**（独立于地块）：天空/太阳/月亮/雾/环境色（docs/20）

## 2. wire 结构（全解码 ✅）

```
f7 (地形区)
 └─ f1 (地形对象) × N          ← "笔刷岛"，多对象即多组（不相连地块的载体）
     ├─ f1: 组 guid
     ├─ f2: 组名（"地形NN"）
     ├─ f3: 变换 {位置, 旋转}   ← 地形锚点（组级）
     └─ f4 (地块) × M
         ├─ f1: 格键 = (grid_x << 16) | grid_z      ← 编码实锤
         ├─ f2: 层位（可省略 = 隐式 L1；层高 2.5）
         ├─ f3: 材质（1..8，可省 = 默认）            ✅ v2 破译
         ├─ f4: 水体（值 1 = 顶部水体）              ✅ v2 破译
         ├─ f5: 路径表面（值 1；强假设）             🟡 v2 对位
         └─ f6: 斜坡（16×type + d 矩阵）             ✅ v2 破译
```

- 字段形态语料 12 种（最简 `(1,2)`，含 3/4/5/6 全套的富块）；f2 可省（`(1,3,6)`、`(1,6)` 形态 = 隐式 L1 带坡）；
- **多地形对象**（v1 未解 → v2 定案）：不相连地形 = 多个 f1 组；语料 28 图存在同键跨组覆盖；**"地形旋转楼梯"样本 = 96/135 组、每组 1-3 块逐级抬升**——组即独立笔刷岛，复杂造型靠组拼装；
- 空白新图 = 单组 400 块全 L1 默认材质。

## 3. 斜坡编码矩阵（统计判决 ✅）

f6 = **16×type + d**。16 族（单层坡，n≈300，四值判决全干净）：

| f6 | 坡降方向 | 证据（高侧邻居 +1 层占比） |
|---|---|---|
| 16（d=0） | **降东** | 西侧 +88% |
| 17（d=1） | **降南** | 北侧 +98% |
| 18（d=2） | **降西** | 东侧 +93% |
| 19（d=3） | **降北** | 南侧 +98% |

- d 序列 = 东→南→西→北（罗盘序）；**坡块置于低侧**（自身层位=低层）；
- **三族形态（2026-10-03 编辑器目检定案 ✅）**：16 族 = **直楼梯**；32 族 = **旋转楼梯（向东旋）**；48 族 = **旋转楼梯（向西旋）**；
- **该引擎地形不存在平滑斜面——"坡"即楼梯**。视觉软化的出路：楼梯化过渡 + 石草混拼材质（5 号）过渡环 + 水体 + 逐层台地 + 实体层遮蔽，而非寻找"平滑坡"。

## 4. 层位语义

- L1 = 默认基面；**L0 = 虚空**（实测注 L0 渲染为空洞——"删除到 0"即挖穿地面，不是低地）；
- 上限远高于三层直觉：语料实测至 **L25**（"战地"全图复刻）；
- 单层落差(±1)配 16 族坡可行走化；多层垂直壁只用于永远不该上下的面。

## 5. 坐标与世界换算（已验证 ✅）

**格键 f1 = (grid_x << 16) | grid_z**，空白画布 grid 100~119（20×20）。

```
world_x = 组.f3.pos.x + (grid_x - anchor_x) * 5
world_y = 组.f3.pos.y + layer * 2.5
world_z = 组.f3.pos.z + (grid_z - anchor_z) * 5
```

空白图锚点 (-547.5, -2.5, -547.5)。RPG 模板(1966) = 3×3 小平台 9 块（grid 99~101），即独立地形对象实例。

## 5c. 水体摆放（目检定案）

水体为**静态水面**（无流动模拟）。三种摆法（平地孤水/坑式/隔离）目检均不浮空，但**坑式最合理**：水块 L1 + 周边地面抬至 L2 成环（下沉式水体）。护城河/水池按此形态构建。

## 5d. 路径表面（f5 = 路径 ✅ 形态学判决）

皇室战争参考图 326 个 f5 块的 ASCII 形态：**三条纵贯车道 + 上下横向桥面**——正是该玩法单位行进的路网。f5=1 即路径表面，与官方"地块顶部表面创建路径"语义对位闭环。富集图：战地复刻(401)/皇室战争(326)/比武台(304)/RPG(272)。
