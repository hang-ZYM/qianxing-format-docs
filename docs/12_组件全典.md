# 12 · 组件全典（实体组件的字节级字典）

> 深挖标准卷：每个组件给出**槽位、出现率、载荷 schema、语义、配方、证据分级**。
> 三源交叉：896 个真实实体普查（16 张地图全量）× 2473 个官方 prefab 模板覆盖 × 官方文档语义。
> 证据：[A]字节实证 / [J]判例 / [D]官方文档 / [H]假设。

## 0. 组件系统定律（先读这个）

```
组件 = { f1: 组件ID, f(组件ID+10): 配置载荷 }    ← 配置字段号 = 组件ID + 10
实体四槽: f5 行为 | f6 编辑器 | f7 AI属性 | f8 表现/引用
```

组件在四槽中的**分布不是任意的**——prefab 全库统计（2473 模板）给出了"每个槽的标配组件集"：

| 槽 | 标配组件（≈全库出现） | 选择性组件 |
|---|---|---|
| f5 行为 | 1(命名), 111, 13, 38, 40, 61, 62, 14(动作组 96%) | 65(交互机关 4%), 80/81/82(宝箱族 2%), 30/31/33(2%) |
| f6 编辑器 | 1(位置), 3, 4, 7(交互参数), 6, 11(挂点树), 12, 16, 17, 19, 20 | 2, 5, 22, 8 |
| f7 AI | 1(命名属性), 3, 18(受击特效), 6, 14, 19 | 26(特殊 4%), 42, 11/12/20/36(孤例) |

**含义**：官方 prefab 出厂自带一套"底盘组件"（位置/挂点/交互参数/受击特效等），实体差异来自选择性组件与配置值。克隆/合成实体时保留底盘、只改配置——这正是从零合成器（synth）能字节级复现官方实体的原因。

## 1. 高频核心组件（出现率 + schema + 语义）

### 槽f6 · 组件1 — 位置/变换 Transform `f11` [A]
```
f11 = { f1:{1: f32 x, 2: f32 y(可省=贴地), 3: f32 z}, f2:{旋转}, f3:{1:sx,2:sy,3:sz 缩放}, f501: -1 }
```
出现 ×896（100%）。y 省略=贴地；缩放默认 1/1/1；f501=-1 常量。
配方：改位置=改 f1 的三个 f32；悬空=补 f2(y)。

### 槽f5 · 组件1 — 命名组件 `f11` [A]
```
f11 = { f1: 实体显示名(utf8) }
```
×896。合成实体时把空名模板 `08015a00` 替换为 `f1:官方名`。

### 槽f6 · 组件7 — 交互参数 `f17` [A+D]
```
f17 = { 1: f32 视觉感知范围, 2: f32 仇恨范围, 3: f32 脱战时间, 5:1, 6:{小配置},
        8-15: f32 × 8 八元素抗性 }
```
×653。**这是怪物侧的战斗参数包**（等同 11 卷组件7 详述）；道具/机关实体无此组件或带简化版。
八元素抗性定量律：倍率 ≈ 0.1/(抗性+0.1)。
官方文档对应：怪物配置面板的感知/抗性项。

### 槽f6 · 组件11 — 挂点树 `f21` [A+D]
```
f21 = { f1: [挂点×N] }  挂点 = { f1:"GI_挂点名", f2:{}, f3:{}, f502:"中文名", f504:层级, f505:"短名" }
```
×626。标准挂点集：GI_RootNode/GI_MonsterRoot/GI_NamePlate(名牌)/GI_HeadMark(头顶)/GI_ChestMark/GI_Body；RPG 模板有自定义点（GI_MoveHead 等，609B 大树）。
官方文档：特效/文本气泡/扫描图标都"挂接"这些点。
配方：挂特效 = f7 槽组件 → {挂点名, 特效模板id}。

### 槽f7 · 组件18 — 受击/被击倒特效 `f28` [A]
```
f28 = { f9:{受击配置}, f10:{被击倒配置}, f11:"GI_RootNode" }
子配置 = { f3:1, f4:1, f7: f32(1.0), f11:1, f503:"受击特效"(名), f507:13, f508:2 }
```
×620。两段式特效声明。

### 槽f7 · 组件1 — 命名属性（实体变量）`f11` [A]
即 docs/05 的实体变量层。896 实体中 890 携带，内容 `{1:1, 2:1, 11:{1:{变量定义}}}`；空壳 `{1:1,2:1}` 也合法。

### 槽f6 · 组件22 — 交互与覆盖色 `f32` [A·金样本]
```
f32 = { f1,f2,f7: 启用覆盖色开关簇, f3: AARRGGBB 覆盖色(高8位=浓度),
        f4: f32 交互距离(100.0), f5: RRGGBB 镜像, f6: 6700, f8: 正片叠底开关, f9: 历史/节点码 }
```
颜色四件套的宿主（详见 11 卷 §4.5）。机关类实体普遍携带。

### 槽f5 · 组件14 — 动作组 MPActionGroup `f24` [A]
×2379(模板96%)。载荷 `{f3:"MPActionGroup"}` —— 行为动作组的声明锚。

### 槽f6 · 组件3/6/17/4/19 — 标志组 [A]
- f6#3：×896，多态（4B 空壳 / 21B 引用 `{f1:{f1:1,f2:guid,f501:20000}}`——UI/模型引用）
- f6#4 `{f14:{f1:1}}`、f6#19 `{f1:1}`：布尔开关（语义待逐一对齐面板）
- f6#6 空 `f16`、f6#17 空：空标志

### 槽f5 · 组件13 — 状态标记 `f23` [A]
`{f4: 0xFFFFFFFF}` ×869。全库常量，语义待定 [?]。

### 槽f5 · 组件38 — 缩放系数 `f48` [A]
`{f1: f32(1.0)}` ×599。尺寸相关系数（待与 11 卷组件1 的体型缩放对齐关系）。

### 槽f7 · 组件6/14 — 空标志 [A]

## 3. 官方"可添加组件"对照（文档侧）[D]

编辑器组件面板可给实体添加的组件（官方文档枚举）：碰撞触发器、自定义变量、全局计时器、单位状态、特效播放、自定义挂接点、碰撞触发源、音效播放器、背包、战利品、铭牌、文本气泡、扫描标签、小地图标识、装备栏（仅角色）。
这些对应字节侧的 f5/f6/f7 组件族——**映射关系待逐一对号**（每个=一次"添加组件→diff"实验或语料对照，本表先立靶）。
