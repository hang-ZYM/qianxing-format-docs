# 23 · 运行语义实证（图跑起来是什么样）

> 证据：[J]。docs/16 §4 给出了执行模型（事件→查→判→做）；这一篇是该模型的**运行时判决书**——每条语义都有一局完整试玩的执行记录作证，并把官方教程语料与实测对齐。做图生成器之前值得通读：它定义"写对了"在运行时的含义。
> 判据来源：一组覆盖执行边/数据边/变量三层/信号/控制流全构型的试件，图执行记录逐条回读核对。

## 1. 求值规则

- **运算流跟随执行流**：运算/查询类节点（无执行位的 Pure 节点）在执行流到达引用它的节点时求值——不是图一开始就全部算好（docs/16 §4 "惰性求值"的运行时确认）。
- **跨执行流取"前一次执行的值"**：当 A 执行流引用了 B 执行流里求值过的查询节点时，A 拿到的是该查询**上一次执行**的结果，而不是为 A 现算——两条执行流之间靠"最近一次值"衔接。

**对生成器的含义**：把查询节点当"缓存变量"用是安全的，但引用发生在其首次求值之前时值是空的——数据依赖必须落在执行依赖之后。

## 2. 事件驱动起点与同帧时序

- 事件节点是图的**唯一执行入口**（57 种事件源，docs/16 §4）；
- **同一帧内多个事件被触发时，顺次执行且时序固定**——不是并发竞态，是确定性的排队；
- 推论：多事件驱动的图行为是可复现的——同构输入必得同构输出，不需要考虑调度抖动。

## 3. 有限循环语义 [J]

以"循环 3 次、连跑 6 轮"的试件实测：

| 语义点 | 实测结果 |
|---|---|
| 迭代次数 | **精确**等于参数——不多不少，无 off-by-one |
| 端语义 | 区间 **1..N 含两端**（start/end_index 都取到） |
| 每轮内部时序 | 循环体按执行线顺序完成，Iteration 出口逐轮触发，End 出口最后触发一次 |
| 跨轮一致性 | 6 轮全部同构，轮间无状态残留（循环变量每轮重置） |

docs/16 §5 的"防死循环设计"预言（只有 for、无 while）就此通过运行时验证。

## 4. 多分支语义 [J]

- `key` 与 `cases` 按值匹配：命中 Case N 则从 Case N 出口流出（实测连续六次命中 case3，零次走默认）；
- 全部不命中走 DefaultBranch 出口；
- 只支持 Int 与 Str 匹配（枚举本质是 Int，docs/16 §2）——生成器不要生成其他类型的 cases。

## 5. 黑板变量的运行态 [J]

图黑板变量（docs/05 §2）在**编辑态是声明池**（f6 列表：名字/类型/初始值），运行时发生一次**转换**：

```
编辑态 f6 声明池 ──(图装载)──→ 运行态变量池（按名字索引）
```

- 读/写节点在运行时按**变量名字符串**寻址（与自定义变量的明文寻址同构，docs/05 §3）；
- 实测：一轮循环里"读总数 → 修改已计数 → 写回"六轮全部一致，无丢失无错位；
- 执行明细中**变量名与运行时值逐条可见**（见 §8 观察面）——变量系统的调试不需要猜测。

**对生成器的含义**：图内变量的名字是运行时契约——改名字等于改寻址，所有引用点必须同步。

## 6. 强类型 → 泛型的连线 [J]

强类型出参（如循环的 current_index: Int）**可以直接连入泛型节点的入参**——泛化方向（concrete → generic）合法；反方向（generic → concrete）需要类型已决议（docs/04 泛型五件套）。生成器可以放心把强类型值传入泛型容器类节点。

## 7. 实体寻址与信号回执 [J]

- **挂载寻址**：图挂在实体上后，事件里的"本实体"寻址在运行时正确解析——碰撞触发器实体触发的图，寻址到的就是该触发器（另一试件复证）；
- **信号链**（docs/15 的运行时半边）：服务器图发信号 → 客户端 Lua 收到 → 回执逐字一致。实测要点：
  - Lua 侧信号处理器注册**必须在 OnInit 生命周期内**完成，晚注册收不到已发信号；
  - 客户端只能向服务器发信号（通信矩阵，docs/15）——双向设计要靠服务器中转。

## 8. 观察面：怎么读到图的真实执行

三层观察通道**本地落盘、机器可读**（前提限定 2026-10-04 补：图执行记录由**编辑器收集器**写入且为**勾选监听制**——编辑器内勾选目标图才记录、每会话重置；**游戏内直接试玩不产生 .gia**）：

| 观察面 | 覆盖 | 形态 |
|---|---|---|
| 图执行记录 | 节点图执行明细：节点触发、变量名与运行时值、连线数据流 | 随关卡存档落盘的日志条目（容器格式与关卡文件同族，docs/10 独立文件族） |
| 客户端脚本日志 | Lua `print` 输出 | 客户端日志文件 |
| 运行时局内存档 | 试玩过程中的世界状态快照 | `.gir` 文件（docs/10） |

开关有两层（编辑器调试日志窗）：**总开关门控脚本 print，树勾选门控节点图执行记录**——只开总开关看不到图执行明细，两层都要开。
