# 11 · 属性系统全典（每个属性写什么）

> f22 属性注册表声明"本图启用哪些属性模型"；实体侧用**组件系统**承载属性值。本卷把两层接起来：**每个属性的语义、字节位置、载荷 schema、写值配方**。
> 证据：[A]字节实证 / [J]判例 / [K]知识库存档 / [H]假设待验。

## 1. 组件系统定律 [A]

```
属性值 = 实体槽位的组件
组件   = { f1: 组件ID, f(组件ID+10): 配置载荷 }     ← 定律: 配置字段号 = 组件ID + 10
实体四槽: f5 行为 | f6 编辑器 | f7 资源（2026-10-04 勘误：原标"AI属性"系语义错标） | f8 表现/引用(带f2=1标志)
```

实测吻合：组件1→f11、组件2→f12、组件7→f17、组件11→f21、组件13→f23、组件22→f32。

f22 注册表（见 10 篇）= 本图启用的属性模型名 + 启用位图；实体组件 = 模型的值实例。


## 4.5 颜色与材质（官方范式 × 字节实证合流）

**官方文档定案**（开发者范式，无需逆向猜测）：
- 自定义颜色 = 在原生色上**叠加**或**覆盖**（叠加模式枚举：覆盖 / 正片叠底）
- **颜色透明度 = 0-100 整数**（浮点传入时向下取整）——半透明的答案
- 节点【修改模型颜色和材质】参数表：目标实体(Ety) / 覆写颜色配置(Bol) / 启用自定义颜色(Bol) / **填充颜色(整数=十进制颜色码)** / **颜色透明度(浮点0-100)** / 叠加类型(枚举) / 覆写材质配置(Bol) / 启用自定义材质(Bol) / 填充材质类型(枚举)
- 自定义材质 = **冰 / 石化** 两种；装饰物颜色/材质可被主物件覆写
- "节点图颜色码" = 当前颜色的十进制代码，供节点图调用

**字节实证**（原生染色样本 diff，含两处勘误修正）：
- 静态侧落点 = 实体 f6 槽**组件22/f32**。**终案（原生改色参考样本认证）**：
  - **f3 = AARRGGBB（覆盖层颜色码，选色器写这里）**
  - **f5 = RRGGBB（24 位 RGB 镜像，同步写；0 省略）**
  - **⚠ f3 高 8 位 alpha = 覆盖层浓度（overlay opacity），不是实体透明度**——50% 红 = 原实体透一半 + 红盖一半；实体本身仍不透明
  - `{f1,f2,f7}` 开关簇 = 启用覆盖；**f8 = 叠加模式开关（1=正片叠底，缺省=覆盖）[A·目检]**；f9 = 历史/节点码字段；f4=100.0f 交互距离
  - **配方**：实体改色 `f3=0xFF+RGB, f5=RGB, 开关=1`；**半透明实体（玻璃感）不可由 f3 达成**——需透明形态实体 + 叠色（见"玻璃三径"）
- **编码陷阱**：颜色 int 按 **int32 带符号 varint** 写——≥2^31 的值（如 0xFF0D20B6）必须写 10 字节负数形式，无符号写法会被当 64 位解析污染（实验 D 例证）
- 官方 UI 色板（文档实证）：`#4A5366BF` 注明"75%不透明度" → **颜色系统 = 8位 ARGB 十六进制**；元素色表：水#80C0FF 火#FF9999 风#80FFD7 雷#FFACFF 草…
- 不可见 = **组件8/f18 删 `f1:1`**（f18 由 {f1:1, f501:1} 变 {f501:1}；PropertyStaticVisible 实锤）
