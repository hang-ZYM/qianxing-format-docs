# 25 · 客户端图与自定义 AI（造物正典）

> 证据：[A][J]。千星的怪物 AI 由**三类客户端图**驱动：决策图（想做什么）、状态图（怎么做）、技能图（单个技能的执行）。这一篇是从零写一只带自定义 AI 的怪的全链正典——实体合成 + 图合成 + 绑定，全部可以不打开编辑器完成（编辑器只用于最后的官方导入与试玩验证）。
> 每条结论都有导入实测背书（五轮判别实验 + 黄金回归逐字节验证）。

## 1. 总览：从零配一只 AI 怪

```
① 怪本体实体（f5 实体条目，prefab 合成或克隆，guid 用 0x408 段）
② 决策图（想做什么：每帧仲裁切状态）      ┐
③ 状态图 ×N（怎么做：巡逻态/战斗态…）      ├ 三类图，格式见 §2-§5
④ 技能图 ×N（技能执行：攻击盒/仇恨/恢复…） ┘
⑤ 绑定：comp80 挂决策图 + comp81 技能背包 + comp82 感官 + comp42 激活
⑥ 阵营矩阵（关卡设置：1玩家↔2造物敌对——没有它挨打/攻击都不入战）
```

选怪决策树：只要"会打人"的杂兵 → **经典版**（放置即活，零配置）；要可编程行为（阶段/巡逻/自定义）→ **AI 版**（必须配图，见 §6）。87 只怪的版本/参数查 `data/monster_registry.json`。

## 2. 图种与身份（id 块）

图身份在图元数据的 id 块里，三类图各占一个段位：

| 图种 | id 块 f2 | 节点引用的 category 段 |
|---|---|---|
| 决策图 | 20007 | **恒 20007** |
| 状态图 | 20009 | **仍 20007**（≠自身 id 块！） |
| 技能图 | 20008 | **20002**（≠决策/状态图） |

id 块完整形态：`{1:10000, 2:<上表>, 3:21001, 5:图guid}`。节点引用段写错 = 编辑器日志 `different category` 拒绝。

## 3. 图条目与元数据（最容易翻车的层）

图条目在图库（f10）里的形态：**meta 外恰好一层包装**（`lf(1, meta)`）。

- 裸 meta = 死；多套一层成三层 = 导入器剥成无名空壳——"恰好一层"是铁律 [A]；
- meta 结构：`{1:id块, 2:图名, 3:图树×N, 100:1}`；
- **f100 = 1 实例化开关** ★：元数据层 field 100 的 varint 1（字节 `\xa0\x06\x01`）。**缺失 = 图在库、树有叶、绑定在、字节与能跑的图同构——但运行时永不实例化**（零日志"雕像"）。编辑器重存从不补它，第三方生成必须手写 [J]；
- **注入永不改图名**——改名 = 导入拒收（机制未明，100% 复现）；新建的图名随意 [J]。

## 4. 树注册（缺 = 导入后图消失）

同类型的图挂同一棵**正典树**，叶 = `{1:叶型, 2:图guid}`：

|---|---|---|

## 5. 实体侧绑定（大脑入口）

| 组件 | 角色 | 载荷 |
|---|---|---|
| **comp80** | 决策图挂载 | 携带 `{1:1, 2:决策图guid, 501:20007}`——AI 版出厂此槽为空，**不填 = 雕像** [J] |
| **comp81** | 技能背包 | `{1:序号, 2:{1:1, 2:技能guid, 3:距离区间}, 12:名}` ×N |
| **comp82** | 感知模板 | f4 入战 / f5 脱战 / f6 领地——引擎仇恨入口 |
| **comp42** | AI 激活 | `{2:1, 53:{...}}` |

配套要求：怪物 guid 必须 **0x408 段**（段错不渲染）[A]；实体要 **f5 + f6 树叶双注册**（缺一不渲染）[A]；底盘属性注册须含 PropertyEnmity [J]。

## 6. 决策图（想做什么）

节点三件套：**起始**（多出引脚）+ **查询**（纯数据节点，不接流程，被下游拉取求值）+ **切换**（挂状态图）。

最小模板（官方"前置条件"形态）：

```
#1 起始 ──引脚1──> #2 切换A ──失败执行线──> #3 切换B
#2 切换A: 是否执行=数据线←#4查询, 状态图=战斗态guid, 序号=1
#3 切换B: 是否执行=真, 状态图=巡逻态guid, 序号=1
#4 查询: 悬空（被切换A拉取求值）
```

语义：**每帧仲裁**——引脚序 = 优先级，条件真的引脚赢并本帧截断；正在执行低优先状态时高优先条件变真 → 立刻抢占切换。可用查询 37 个（交战中/正在放技能/在领地/距离×4/阵营敌对/获取目标实体…全表见 07 卷客户端图域）。

## 7. 状态图（怎么做）

官方形态两要点（官方教学示例图定案）：

1. **失败执行线 = 同族备胎链**——技能 111→失败→技能 222→失败→技能 333，同类行为互为备胎；官方从不把失败线用于跨行为类型交接；
2. **跨行为的组织 = 起始节点多引脚并列**——引脚①挂技能备胎链、引脚②挂巡逻，引脚序 = 优先级，①进不了才轮 ②。

常用态模板：

```
巡逻态（黄金回归 378B 逐字节验证）:
  起始.引脚1 → 巡逻{是否执行=真, 模板序号=1, 最近路点=真}
战斗态-贴身型:
  引脚① → 追击{是否执行=真, 触发[2.5,10], 停止=2.5, 速度=3602跑, 持续=5}
  引脚② → 执行技能{是否执行=真, 技能序号=1}
  期望: 距离>2.5→①追击; 贴脸≤2.5→①进不了→②技能
战斗态-炮台型: 引脚①→技能链, 引脚②→追击
```

战术 kernel 全表（壳 id 2001xx）：

| kernel | 战术 | kernel | 战术 |
|---|---|---|---|
| 4020 | 闲逛 | 4019 | 逃跑 |
| 4018 | 追击 | 4021 | 返出生 |
| 4013 | 静止 | 4022 | 对峙 |
| 4014 | 移到点 | **4023** | **巡逻** |
| 4015 | 移到实体 | 4012 | 执行技能 |
| 4000 | 起始 | 4011 | 切换 |

交接几何：追击的**进入条件 = 距离∈[触发最小, 触发最大] 窗口**，停止距离只管持续移动——贴身型的触发最小距离 ≥ 碰撞极限（约 2.2，建议 2.5）才能让贴脸时落出窗口、轮到技能引脚 [J]。速度枚举：3601 走 / 3602 跑（采样实锤）；其他枚举值用到前先实测，勿推理。

## 8. 技能图（单个技能的执行）

形态：壳节点（f8={1:6}）+ 执行节点。攻击盒模板的槽位表：

| 槽 | 参数 | 槽 | 参数 |
|---|---|---|---|
| 0 | 阵营筛选 | 9 | 长方体缩放 |
| 3/4 | 伤害系数/增量 | 10 | 球半径 |
| 8 | 攻击盒类型 | 11-15 | 扇形五参 |

技能侧挂接链：技能定义（guid 用 0x470 段）→ 动画 → 轨道事件点 → 实体 comp81 引用（序号 + 技能 guid + 距离区间 [1,3]）。执行节点库 30 个（攻击盒×4 / 仇恨全套 6 / 恢复生命 / 瞬移 / 转向 / 嘲讽 / 冷却五件套…）。

## 9. 客户端图编码铁律（与服务器图的方言差异）

| # | 铁律 | 违反后果 |
|---|---|---|
| 1 | **数据连线写在目的（输入）引脚的 f5**，载荷 `{1:源节点idx, 2:{1:4}, 3:{1:4}}`（引用源出参 sig） | 画布不渲染线 |
| 2 | 流程连线的目标节点必须有 (1,0) 入引脚（起始节点与纯数据查询节点除外） | `can't find pin` |
| 3 | 数据引脚 kind：入参 = 3，出参 = 4；查询节点的出参引脚 = (4,0) 且带值 | 条件不生效 |
| 4 | **全部参数槽物化**（未设 = 空类型声明） | 参数面板红叹号 |
| 5 | **浮点值必须 f104 fixed32 位型**——写成 varint 位型编辑器读不出 | 参数面板全空 |
| 6 | 值的 `'2':1` 标记 = 用户显式设置；编辑器自动物化的默认槽无此标记 | 与原生样本 diff 噪声 |

> **方言统一注记（2026-10-03 更新）**：服务器图与客户端图的连线方言一致——执行边存**源**引脚（f1=目标）、数据边存**目的**输入引脚（f1=源）（docs/22 §3 勘误后的终审口径）。生成器两边通用，无需区分。

## 10. 排错速查（编辑器日志 → 病因 → 修法）

| 日志/症状 | 病因 | 修法 |
|---|---|---|
| `add connection failed [1,0]` | 目标缺入引脚 | 流程目标物化 (1,0) |
| `can't add node / different category` | 节点引用段错 | 恒 20007（技能图 20002） |
| 切换参数红叹号 | 槽位错位/缺失 | 按原生 schema 全序物化 |
| 画布空白但运行正常 | 图条目包装层数错 | 修正为恰好一层 |
| 导入后图消失 | 无树注册 / 改了图名 | 补树叶 + 不改名 |
| **运行时零日志（雕像）** | **缺 f100** | 元数据层补 `\xa0\x06\x01` |
